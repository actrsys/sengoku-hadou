# r865 エンディング演出中の旧タブ失効を検出する

## 正本と判断

- ChatGPTライブラリ直下 `sengoku-hadou-main-r864-fonts-folder-empty.zip`（内部版r864）。
- `EndingSystem.playEndingSequence()` の暗転、待機、スタッフロール、タイトルへの引継ぎを点検。ターン世代・画面状態・演出所有権の検査に、タブ操作権が含まれていなかった。
