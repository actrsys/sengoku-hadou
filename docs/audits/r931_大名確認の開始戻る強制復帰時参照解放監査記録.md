# r931 大名選択確認の終了時に旧操作・画像・名前表示状態を解放

- **監査対象**：ChatGPTライブラリ `sengoku-hadou-main-r930-scenario-start-resident-lifespan-sync-complete.zip`（r930）。r927反映の共通マスターを維持。
- **監査範囲**：新規開始・1560年の三好寿命常駐イベント初期同期、セーブ復元・歴史イベントON/OFF、さらに `UIInfoManager.showDaimyoConfirmModal()` からゲーム開始・大名選択に戻る・`UIManager.forceResetModals()` によるタイトル復帰。
- **重要度**：中。大名を選択して開始した後も、固定ボタンの `onclick` が旧勢力の `onStart` を閉包で保持したままだった。また確認画面の途中で強制タイトル復帰すると `body.hide-daimyo-labels` が残り、再度シナリオを選んだときに勢力名が隠れ得た。

## 到達経路と修正

- 通常の到達経路は「シナリオ選択→大名選択→勢力詳細→開始」および「勢力詳細→戻る」。別タブの操作権移転・タイトル復帰では確認画面の途中でも `forceResetModals()` に到達できる。
- `UIInfoManager.releaseDaimyoConfirmState()` を専用View内の**単一の終了窓口**として設け、固定ボタン2個の `onclick`、確認内容DOM（顔画像参照を含む）、確認ボタン表示・名前非表示class・選択中大名IDを解除する。新しいタイマーや監視は追加しない。
- 通常の開始・戻ると、`UIManager.forceResetModals()` の3経路から同じ専門終了処理を呼び出す。強制リセット時だけ大名選択専用レイアウト `body.daimyo-select-mode` も解除し、通常の戻るでは同モードを保持する。
- `GameManager` のシナリオ選択・開始／歴史イベント条件・寿命計算・セーブ形式・CSS・管理Excel/BINは変更しない。
- r930寿命イベントの追加監査では開始→月初→月末・歴史イベントOFF・保存復元の現行契約に新たな不整合は確認されず、無改修とした。
