# r959 登録停止済み荒木村重旧イベントのコメント実装撤去 — 構造監査

## 対象・範囲

- 正本：ChatGPTライブラリの `sengoku-hadou-main-r958-info-list-text-compression-unified-complete.zip`。
- 適用規則：`ARCHITECTURE.md` の「改修の必要性・死んだコードを残さない・テスト正本・画面と判定を変えない」、`docs/manual/MAINTENANCE_POLICY.md`、`docs/manual/TECHNICAL_REFERENCE.md`、旧r369の史実時系列再設計方針。
- 対象：`js/event/historical_event.js` にコメントとして残った旧イベント2件（`historical_araki_takeover`、`historical_murashige_submission`）と、それらのソース文字列を検査する古いテスト。国主・城主、外交、戦後処遇の**現在の実行処理**は変更対象外。

## 新規発見と実到達性

- 旧イベントはr369で、1570年池田家の内訌と1574年伊丹攻略・有岡改称を混ぜていたため登録停止され、**387行のコメントアウト実装**として残存していた。
- 当該387行は空行以外すべて`//`から始まり、実際には`window.GameEvents.push()`を呼ばない。現在の登録イベントからは到達しない。
- 一方、既存回帰テストには、停止中のコメント実装の軍団席次・退避・所属・軍師処遇等を検査するケースが含まれていた。これらは現行実行コードの品質を保証しない。
- 停止の判断・時系列の背景は既存の`docs/audits/archive/architecture_legacy_revision_notes_through_r767.md`のr369節で保持されている。今回は史実イベントの仕様を新しく採用せず、将来の再設計判断も行わない。

## 改修内容

- `js/event/historical_event.js`：旧イベント2件の**コメントアウト実装387行を撤去**。登録停止の経緯と旧監査記録への参照だけを短いコメントで残す。現在登録されている史実イベントのソースは変更しない。

- `js/config.js`：版情報の唯一の正本を `r959` に更新。
- 新System、ラッパー、永続キャッシュ、仕様変更、CSS・HTML・画像・音声・シナリオ・Excel・BIN変更はなし。
