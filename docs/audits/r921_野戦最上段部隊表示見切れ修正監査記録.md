- 新版：r921。範囲：`FieldWarManager` のマップ描画余白、スクロール・ズーム座標、CSSの描画境界、実ブラウザ回帰検査。
- ゲーム計算・AI判断・部隊配置・兵科アイコンと兵数の相対位置は変更しない。

## 不具合と実到達性

- 野戦マップ最上段（偶数列y=0）の部隊では、兵科画像・兵数が凸形の上に約19px張り出す。最大兵力の凸形もHEXの上端から最大2.5pxはみ出す。
- 従来は `#fw-map { overflow: hidden }` とマップ座標原点y=0のため、最上段の付属表示が欠ける。スクロール領域も上端をクリップし、カメラのスクロールでは負座標へ戻せない。
- 実装の `initMapElements()` / `updateMap()` と地形・画像を使ったPC 1280×720とスマホ360×640のChromium描画スクリーンショットで見切れを再現した。ユニットの描画上の付属表示上端がスクロール領域上端より上に出ることを矩形値でも確認した。

## 改修

1. 兵科・兵数・凸の相対位置はそのまま、マップの外側に20論理pxの上余白を拡大率に応じて確保する。マップ内部のHEX、部隊、経路探索の数値は変更しない。
2. マップ内部 `overflow` を `visible` とし、外側の `fw-map-scroll` を唯一のクリップ境界として維持する。背景や戦場の表示域は拡張しない。
3. `applyMapScale()` のズーム中心変換と `scrollToUnit()` / `scrollToCenterPos()` のカメラ座標、および部隊情報パネルの位置計算に共通の上余白を反映する。初回スクロールや通常のsmooth追従の条件は変更しない。
4. 描画検証用fixtureを一つ追加し、実 `FieldWarManager` でPC/スマホの各ズーム状態とプレビューを検査する。新しいtimer、描画レイヤー、操作ハンドラ、マスター変更なし。
