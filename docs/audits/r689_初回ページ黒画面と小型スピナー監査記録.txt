# 戦国覇道 r689：初回ページ黒画面と小型スピナー表示

基準：r688完全版ZIP。正本：ARCHITECTURE.md のAI改修方針、初回起動・UI責務、r687/r688の起動構成。

【依頼・確認した事実】
- 初回ページ前の専用ロード幕にはタイトルロゴ、説明文、進捗率、進捗バー、装飾線があり、ユーザーはそれらの撤去と「黒背景＋画面右下の小さな回転表示」を指定した。
- この幕はゲーム本編より前に描画するため、index.html冒頭の最小styleで表示する必要がある。本編の通常ロード幕・データ進捗表示は別UIManager責務。

【変更】
- index.html：初回幕の背景を#000へ。右下の18pxスピナーのみを通常表示し、文字・バー・ロゴ・百分率を撤去。PC/スマホとも画面右下に配置し、safe-area-insetを考慮。prefers-reduced-motionのアニメーション停止に対応。必要な最小CSSだけを先行styleへ保持。
- js/startup_loader.js：起動中の進捗DOM更新を削除。本編CSSとJavaScriptの読み込み順・バッチ間描画機会・起動完了後の幕解除・タイトルフォント期限は変更しない。
- 起動失敗時だけ最小限の失敗文言と「再読み込み」ボタンを表示。途中失敗を無反応の黒画面にしない。
- ゲーム本編の #global-loading-screen、ゲームルール・マスター・AI・セーブ形式は変更しない。

【検証・制限】

- Nodeロジックテストは1,162件成功。既存のPC/スマホ実ブラウザ画面回帰も正常終了。
