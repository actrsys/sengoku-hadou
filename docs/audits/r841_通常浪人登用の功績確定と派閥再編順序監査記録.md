# r841 通常浪人登用の功績確定と派閥再編順序

## 到達可能な問題と修正前再現

- プレイヤーの「登用」命令は `CommandSystem.executeEmploy()` を通る。自領の拠点にいる浪人を担当武将が登用できた場合、従来は `AffiliationSystem.joinClan()` が仕官直後に受入家の派閥を再編し、**その後**で登用担当者の功績を加算していた。
- `FactionSystem.updateFactions()` の派閥主候補には功績500以上という条件がある。担当者の功績が490、登用対象の最大能力が100なら命令成功後の功績は520となり、通常プレイの成長で資格境界を跨ぐ。
- 製品の `CommandSystem` と `AffiliationSystem.joinClan()` を組み合わせ、派閥再編時の担当者功績を記録する新規回帰テストを**修正前に追加**した。実際に再編時490、命令終了時520となり、期待する最終状態の再編テストが失敗した。

## 最小改修と責務

- `CommandSystem.executeEmploy()` は命令全体の確定順序だけを管理。`AffiliationSystem.joinClan(target, ..., {deferFactionUpdate: true, deferUI: true})` を使用し、浪人の所属・活動状態・旧派閥破棄は所属の正本に委譲する。
- 登用担当者の従来どおりの功績加算と承認欲求更新を完了してから、既存の `FactionSystem.updateFactions(playerClanId)` を**受入家に一回だけ**実行し、その後画面を一度更新する。
- 他の単発 `joinClan()`、諸勢力取込、引抜、月次自動仕官、登用成功率、功績報酬量、忠誠、派閥選出式は変更しない。
- テストの旧簡易Fixtureは `updateFactions()` と `updateUI()` を省略していたため、製品コードに互換用条件分岐を増やさず、そのFixtureに必要な正規契約を追加した。
