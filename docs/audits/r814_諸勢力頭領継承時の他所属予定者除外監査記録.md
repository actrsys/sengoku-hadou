# A-143 諸勢力頭領継承時の予定所属の保全（r814）

## 実ゲームでの到達性

`KunishuSystem.processEndMonth()` は有効な諸勢力ごとに `checkDestroyed()` を実行する。頭領が死亡して在籍中の構成員からいなくなり兵力が残る場合、未登場の一門も後任候補へ入れる。従来は「未登場・血縁・出生済み」だけを条件にし、所属予定の別大名家・別諸勢力の武将まで選択していた。選出後は `belongKunishuId`、`clan`、`castleId`、`status` を書き換えて早期元服させるため、単なる表示だけの誤りではない。

1570年シナリオの実データには、入来院家（頭領：入来院重嗣）の一門判定に島津豊久（島津家予定所属）が入り、因島衆（頭領：村上亮康）の一門判定に来島通総（来島衆予定所属）が入る組み合わせがある。頭領死亡は自然死・戦死等の進行で発生し得る。候補選出の誤りを長期観戦で観測したわけではなく、実データと実際の月末経路を踏まえた結合回帰で再現した。

## 原因・最小修正

諸勢力Systemの後任候補抽出で `clan === 0` かつ `belongKunishuId === 0` または当該諸勢力IDという予定所属資格を追加した。別所属予定者は血縁があっても除外する。候補順位、現役構成員、所属未定の未登場一門、候補不在時の自動頭領生成、死亡・在城の専門Systemは変更しない。別の部署へ継承の決定権を移さず、所属書換には既存 `AffiliationSystem` の低レベル窓口を使う。

## 再現・回帰

- 新規2件は修正前にいずれも失敗。別大名家・別諸勢力の予定者が後継者になり、現役構成員がいる場合にもそれらが優先された。
- 修正後は同じ諸勢力の予定者が早期元服し、他所属予定者が未登場・元所属のまま残ること、該当の早期元服者がいなければ現役構成員が継ぐことを確認。
- 検証の対象となる4,042人の共通武将データ、1570年の所属予定、FamilyLinkerの関係構築を照合した。管理Excel/BINの変更はない。
