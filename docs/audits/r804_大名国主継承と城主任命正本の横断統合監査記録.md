# A-132 大名・国主継承と城主任命の正本統合（r804）

## 実到達経路と修正理由

前版r803までの複数戦死では、国主継承時の同時戦死者を候補から除外していたが、大名家督の現役以外の一門（未登場・浪人・諸勢力所属）の候補資格に同じ除外が行き渡らなかった。これらはAI勢力の家督継承で到達可能で、同じ合戦で死亡予定の者を一時的に大名へ任命し得た。

また、死亡処理の城主自動選考を保留しても、別拠点にいた後任者を当主・国主の居城へ移す `leaveCastle()` が出発元で城主を即時再選出した。大名継承の `changeLeader()` も全拠点の城主更新を即時に実行した。同時戦死を扱う桶狭間・川中島では、死亡予定者を出発元の仮城主へ選出する恐れがある。

城主任命では、所属Systemの自動選考だけでなく、軍団任命、個別城主任命、家督相続、史実イベントでの正式指定、敗戦・接収、外交上の割譲が `Castle.castellanId` と `isCastellan` を別々に書き換えていた。正本更新と表示フラグ同期の責務が分散していた。

## 改修

- `LifeSystem._collectSuccessionCandidates()` と `_sortSuccessionCandidates()` に家督・国主共通の候補資格／比較軸を集約。現役、未登場、浪人、諸勢力一門すべてで同時死亡・処断予定者を除外する。大名の年齢優先、国主の現役別軍団・大名除外と同軍団補充、プレイヤーの家督選択は変更しない。
- `executeDeath()` から大名／国主継承へ、更新保留コンテキストを維持して伝播する。後任の旧居城を `affectedCastleLordIds` に追加し、`leaveCastle()` での仮城主任命を保留。`GameManager.changeLeader()` の全城主更新も一括死亡中のみ保留する。両史実イベントの最終確定対象と共有する。通常の単発死亡・家督相続は従来どおり即時確定する。
- 城主の唯一の低レベル代入窓口として `AffiliationSystem.setCastellanRaw()` を新設。同じ正本に対して旧城主の表示フラグを除き、新城主IDと表示フラグを同期する。`updateCastleLord()`／`electCastellan()` の選考の意味、各種正式任命の資格・履歴・委任・軍団ルールは残し、正本の反映だけ統合する。
- 通常の個別城主任命・国主任命・家督・国主相続、外交割譲、戦争での接収・落城・撤退、史実イベントの指定城主や旧所属喪失、滅亡整理に残っていた直接代入も低レベル窓口へ統合した。新たなリーダー職の大名新設（独立・諸勢力旗揚げ）・軍団解散等の固有の処遇決定を、危険な一律処理へ置換しない。
- 既存ロジックの正本を実行する最小モックへ回帰試験を更新し、個別の偽 `setCastellanRaw()` を多数作らず共通fixtureへ集約した。城主在職バッジの範囲と書換経路の新規テストも追加。
- 管理Excel／BIN・顔画像・CSS・セーブ形式・画面は変更していない。
