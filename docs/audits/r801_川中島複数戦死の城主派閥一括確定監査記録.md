# A-129 川中島イベントの複数戦死による仮城主・派閥途中再編の抑止（r801）

## 到達性と修正前の再現

r800を基準に `historical_kawanakajima`（1561年9～11月の月初前）の `checkCondition()` を通す結合テストを追加した。上杉謙信・武田信玄・北条氏康がそれぞれ大名、上杉が武田と北条に敵対し、武田領の海津城が上杉領に隣接し、必要な武田・上杉家臣が活動中で、プレイヤーが上杉・武田以外という成立条件を満たす。

この条件では勘助・信繁の居城の制限がない。海津城で山本勘助が城主、武田信繁が同じ拠点の家臣である配置は、通常の所属・城主ルールで実現可能。イベントで2人とも戦死するが、r800は `LifeSystem.executeDeath()` の都度城主・派閥を更新するため、勘助死亡直後に信繁を仮城主に選出してから信繁が死亡する。実際の `LifeSystem` / `AffiliationSystem` / 史実イベントを結合したテストで **海津城主更新2回** と不要な任命履歴を確認した。さらに死者ごとの途中派閥再編2回が、イベント終了時の共通再編に重複する。r800の既存1,301件は成功、追加テストのみ失敗。

## 最小修正と責務

- `LifeSystem.executeDeath()` に任意の `context.deferCastleLordUpdate` を追加。城主死亡時の即時補充だけ保留し、死亡・家族・官位・国主・家督・外交人質の既存の専門処理は変更しない。無指定の通常死亡は従来の即時更新。
- 川中島イベントは山本勘助・武田信繁の各死亡を `executeDeath({skipNormalMessage:true, deferCastleLordUpdate:true, deferFactionUpdate:true})` へ委譲する。戦死時に城主だった人物の元拠点を重複なく記録し、2人の死後に `GameManager.updateCastleLord()` の既存窓口で一度だけ確定する。城主不在を認める。派閥・画面は `EventManager` のイベント終了時共通更新を使用。
- 対象人物・発生条件・戦死の順序・台詞・BGM・能力・死亡後の相続処理・管理データは変更しない。
