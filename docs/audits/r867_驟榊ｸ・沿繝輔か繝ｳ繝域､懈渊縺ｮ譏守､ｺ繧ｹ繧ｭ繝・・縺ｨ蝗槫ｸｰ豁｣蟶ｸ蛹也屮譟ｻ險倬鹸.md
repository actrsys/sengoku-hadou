# r867 配布版フォント検査の明示スキップと回帰テスト正常化

## 対象と到達条件

- 正本：ChatGPTライブラリ `/2026-11-10/sengoku-hadou-main-r866-fonts-folder-empty.zip`（内部版 r866）。
- 現行開発マニュアルは、配布ZIPからフォント実体を除外し、`data/fonts/` の空フォルダを残して利用者側が投入する運用を要求する。
- r866配布版をそのまま展開し `node tests/run_tests.js` を実行すると、r540の1検査が `data/fonts/title-abashiri-mincho.woff2` の `statSync` で `ENOENT` となり、ロジック回帰が **1,407成功・1失敗**になる。これは本体ロジックの失敗ではなく、配布構成と実体必須テストの不一致。

## 最小修正

- `tests/run_tests.js` のr540検査を、**コード・CSS・HTMLの参照・ロード順序に関する常時実行の回帰**と、**実体サイズ比較だけの環境依存検査**に分けた。
- フォント4実体が全て未配置なら実体サイズ検査のみ `SKIP` と明示して計数する。1つでも配置されていれば4ファイルの存在・小型版と完全版のサイズ比を従来どおり厳密に検査し、一部欠落なら `FAILED` とする。`data/fonts/` 自体は配布時にも必須なので常時検査する。
- テストランナーの最終行を「成功・失敗・スキップ」の別集計とする。テストで本体の `SaveManager`、ゲームルール、UI、フォント参照先や実体を変更しない。
- `tests/README.md` にこの区別を記し、版表示の正本 `js/config.js` だけを r867 へ更新した。管理Excel・BINは無変更。
