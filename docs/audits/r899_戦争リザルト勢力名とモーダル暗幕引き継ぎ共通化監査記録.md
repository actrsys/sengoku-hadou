# r899 戦争リザルトの勢力名・勝敗視点・表示順序と共通暗幕引継ぎ監査

## 対象・方針
- 基準：r898 完全版。戦争結果・メッセージ切替のちらつきが複数画面に発生するとの報告を受け、各画面へ個別タイマーや二重の暗幕を増やさず、UIManager の共通表示境界で扱う。
- 戦闘の計算、各勢力の勝敗、領地の確定、音声の既存契約、メッセージ本文のゲーム内容、セーブ形式は変更しない。

## 確認・修正した問題
1. **地図点滅が攻城戦の後ろに隠れる。** `WarManager.endWar()` で戦域点滅を開始する前に `UIManager.setWarModalVisible(false)` の既存閉鎖を await する。同メソッドの非表示分岐が共通 `closeCoveredViewAfterRecovery()` の Promise を返し、地図復旧・カメラ調整・描画境界の完了を待てるようにする。地図点滅の2秒・制圧色演出順は維持。
2. **操作部隊が全滅すると当事者の敗北が第三者向けに表示される。** 結果の視点は操作中フラグ `isPlayerInvolved` でなく、終戦時確定済み `isPlayerFactionInvolved` で判断。勝敗判定の正本は既存の攻守勢力関与判定を維持。
3. **結果に「当家」と表示される。** 専用リザルトの攻守欄、AI処理経由の結果本文、諸勢力鎮圧の結果本文は、`getClan()` / 既存実名参照を使って実際の勢力名で表示。ほかの通常会話・通常ログの「当家」表現まで一括変更しない。
4. **会話・結果・各種モーダルの間に地図が一瞬露出する。** UIManager が一つの `#modal-handoff-backdrop` を管理する。固定モーダルの可視変化を共通監視し、最後のモーダル終了時だけ前画面と同じ暗幕を維持する。次のモーダルが開けば解除。新しい会話の顔画像decode待機中は短い固定猶予を超えても維持する。通常の単独終了は描画境界の復旧後に解除。
5. **戦争リザルト後に非同期の戦後処理が続く。** 専用結果Viewは共通 `beginModalHandoff()` を利用し、処理Promiseの完了まで暗幕を引き継ぐ。全画面の野戦・攻城戦は既存の `closeCoveredViewAfterRecovery()` を正本とし、追加暗幕を掛けて地図点滅を覆わない。強制タイトル復帰では共通暗幕の寿命を失効させる。

## テストと証拠
- ロジック：`node tests/run_tests.js` **1,456成功・0失敗・1スキップ**。
- PC、スマホ、軽量スマホのChromiumで「通常メッセージ終了→空白→次メッセージ」「戦争結果の半透明暗幕維持」「顔画像読込中」「非同期待機」「強制解除」「全画面攻城戦→地図」を検査。共通暗幕が空白区間を覆い、次画面に残留しないことを確認。
- 既存の `node tests/run_visual_tests.js` 成功。
- `tools/check_manual.py` と `tools/verify_excel_bin_parity.py` と `tools/verify_release_sources.js`、近似シミュレーション4件成功。
- 実ゲームで複数時間の連戦や、全イベントの操作連鎖を手動で踏破したわけではない。共通管理下の固定モーダルを対象とした回帰であり、独自のイベント地図など他種画面は専用の既存引継ぎ契約を維持する。

## 差分と責務
- `js/ui.js`：固定モーダル間の暗幕正本、解放の寿命、攻城画面の復帰完了契約。
- `index.html` / `css/style.css`：共通暗幕の静的DOMと外観。
- `js/ui_war_result.js`：結果確認から戦後非同期処理への引継ぎ。
- `js/war_effort.js`：地図点滅前の画面復帰、結果ラベルと実勢力名。
- `js/config.js`：版番号。`tests/run_tests.js`：新旧契約を検証。
