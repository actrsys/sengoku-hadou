## 2. 新規発見・修正（SH-BUG-005・中）

### 再現条件と因果

1. プレイヤー参加野戦で、自軍総大将のターンに「命令→撤退」を選ぶ（`js/field_war.js` の `initUI()` 内の `fw-btn-retreat.onclick`）。
2. `showDialog(..., {closeBeforeOk:true, closeBeforeCancel:true})` の「はい」を確定すると、r964では確認コールバックが `this.endFieldWar(...)` を**呼ぶだけ**で、そのPromiseを返さない。
3. `UIManager.processDialogQueue()` は `closeBeforeOk` 時に `beginModalHandoff()` で共通幕を保持するが、コールバックの戻り値がPromiseでなければその所有権を**同期的に解放**する。野戦終了の事前イベントは `await processEvents('before_field_war_end')` を含み得る。
4. したがって通常のゲーム操作に存在する非同期完了契約に欠落がある。ただし既存の野戦全画面が背面を覆うこともあり、実端末で空白フレームが発生することまでは確認していない。

### 再現・差分

- 製品の `FieldWarManager.prototype.initUI()` で実ボタンの `onclick` を設定し、総大将の「撤退」確認コールバックを呼ぶテストを追加。`endFieldWar()` は未完了Promiseを返すスタブとして完了境界を測る（実戦の全戦後処理を模したものではない）。
- **改修前**：`1530 passed / 1 failed / 1 skipped`。コールバック戻り値は `undefined`、テストは期待通り失敗。
- **改修後**：`return this.endFieldWar(...)` の一語を追加。共通UIへ同じPromiseが戻り、未完了の間は契約上完了扱いにならないことを検証。既存の一般部隊撤退処理は変更しない。
- 影響：`js/field_war.js` の総大将撤退確認の1行のみ。`js/config.js` の版番号は正本1か所をr965へ。 `tests/run_tests.js` に専用回帰1件を追加。

## 3. 既存未解決事項の新しい調査

- **SH-BUG-001**：製品コードの全 `checkEndCondition()` / `finishFieldWarWithNotice()` / `endFieldWar()` 呼出位置を列挙。`processQueue()` のラウンド終了、`nextPhaseTurn()`、攻撃演出後の総大将消滅、AI総大将の撤退、総大将の手動撤退を区別。既存の世代付きタイマー `_scheduleFieldWarCallback()` は戦闘世代失効を確認するが、**通知表示後に戦闘activeを落とす仕様ではない**。人工的な再呼出しで通知を飛ばす既知の弱点は残り、通常操作からの二重到達は今回も未立証。繰返しの人工注入試験は実施せず。
- **SH-BUG-002**：`TurnManager.endMonth()` の順序を、史実事前イベント→派閥→独立→外交→諸勢力→寿命→史実事後イベント→月送りと確認。`try/finally` で同月実行権は解放する一方、途中の専門Systemに未捕捉の自然例外があれば前工程の副作用だけが残る可能性は構造上残る。イベント個別の条件判定・実行は `EventManager.processEvents()` 内で捕捉される場合があり、**人工例外から自然発生を推論できない**。専門Systemでの具体的な自然発生条件は未確定。
- 実ブラウザで現行1560年シナリオを観戦開始し月末自然進行を計測する追加検証を試みたが、ChromiumがローカルのゲームURLを `net::ERR_BLOCKED_BY_ADMINISTRATOR` として拒否した。**未検証**。既存の `document.write` 式PC/スマホ視覚回帰は実行でき、今回も通過したが、実シナリオの自然観戦と同一視しない。
- 次回SH-BUG-001は実ゲームを開けるブラウザ環境で、通知前後の `_fieldWarGeneration`、`active`、`turnQueue[0]`、予約処理・終了判定の呼出時系列を観測する。SH-BUG-002は同環境で実データの月末を通し、エラーが起きたときの最後の `month_end:*` 診断キーと担当Systemを特定する。証拠が得られなければ期限なき「保留」でなく、到達可能な経路の検証状況と環境制約を記す。
