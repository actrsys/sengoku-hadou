# 戦国覇道 マニュアルの継続保守体制・追跡可能性監査（r767・文書／検査ツールのみ）

## 対象と主な結果

旧版の原文保全を維持しつつ、今後の規則変更を「現行ルールの更新・技術リファレンスの参照・履歴原文の保存・検査」に分離した。ゲーム仕様・コード・管理データは変更していない。

- 現行 `ARCHITECTURE.md` は依然として必読の単一入口。新しい開発上の禁則事項はここに反映し、過去の改修経緯を章頭へ積み増さない。
- `docs/manual/MAINTENANCE_POLICY.md` に更新・訂正・撤回・配布の手順、資料の役割と優先順位を明記。これは運用手順であり、もう一つのゲームルール正本ではない。
- `docs/manual/rule_registry.json` に重要規則22件の安定ID・担当・探索用キーワードを登録。本文はマニュアル側だけとし、台帳に規則の全文をコピーしない。
- `tools/check_manual.py` で規則IDの欠落・重複・未登録、リンク切れ、原文の改変・欠落、履歴と現行規則の表示区分を検出する。
- 前回の再監査で旧優先規則52行が**技術リファレンスと歴史資料の両方へ重複**していたことを確認。重複収録分だけを歴史資料から削除した。旧マニュアル原文自体は `226+284+1773=2283` 行として再構成でき、SHA-256 `ff94e5283e37b6e444491af6b8a60c66998f1e54c3cfbce299336bf6b21db49c` と一致する。

## 優先順位の監査

現在の明示的なユーザー方針が最優先。現行マニュアルは開発時に守る基本規則、技術リファレンスは当該領域の詳細設計・古い原文照合、現行コードとExcelは実態の確認元、監査記録・旧原文は過去の判断を調べる非規範資料と整理した。過去に撤回された「会話中の月替わり・ロードを通常不具合とみなす」「徴兵ゼロの過剰抑止」「城主必置」「固定本拠」等は現行ルールへ再採用しない。未登場武将・外交・婚姻・死亡・ロード幕などの例外は短文化で失われないよう従来条文を維持した。

## 確認方法と限界

- `python tools/check_manual.py`：正本と台帳の一致、相対リンク、旧原文SHA一致、役割表示の検証。
- `node tests/run_tests.js`：製品側の既存回帰を再実行する。文書・検査ツールのみの変更のため、ブラウザ画面・AI長期観戦の挙動変更はない。
- 自動検査だけで規則の意味矛盾、最新ユーザー指示の反映漏れ、現行コードの全分岐との一致を証明できない。領域ごとの実装確認は引き続き必要。

## 変更原則

重要規則の文面を更新しても同じ論点のIDは保持する。廃止・置換した内容は現行本文から取り除き、必要な経緯と理由は新しい監査記録へ残す。自動チェックで原文の欠落を防ぎつつ、機械的なチェックのためだけに規則を追加しない。
