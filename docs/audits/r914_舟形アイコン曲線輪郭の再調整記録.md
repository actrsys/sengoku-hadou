# r914 舟形アイコン曲線輪郭の再調整

## 対象と原因
- 正本: ライブラリr913完全版。野戦海上の `ship_*.webp` 12種と影1種。
- r912は元画像にない凹みと内部の不要な線を生じ、r913は線を除いたが輪郭に折れ・角張りが残った。
- r911の元シルエットを比較基準とし、既存の色・画像名・画像寸法・用途を維持したまま外形だけを滑らかにする。

## 修正
- 画像輪郭を滑らかな連続曲線として定義し直し、輪郭と相似の内側オフセットで黒外周・陣営色（総大将は白）・単色内部の3領域を描画。中間の装飾線やハイライトは設けない。
- 舟の先端と後端の幅、上下の平らな端、左右対称、最大横幅と長さを概ね元画像に合わせる。形状に凹み・くびれを作らない。
- 影も同じ滑らかな外形で作成。透明WebPの122×218px、旧パスへの参照・CSS・JSの読み込みやゲーム判定は不変更。
- 色はr911の元画像から採取。検証用のプレビューはソース外の独立ファイルとしゲーム本体へ追加しない。

## 検証
