# r924 強制画面リセット時の共通一覧の後始末統一

- 取得元：ChatGPTライブラリの `sengoku-hadou-main-r923-legion-council-result-handoff-complete.zip` 完全版。内部版r923を確認。
- 対象：`UIManager.forceResetModals()` と `UIInfoManager.closeCommonModal()`。通常の一覧終了、画面引継ぎ、タイトル復帰を照合。
- 実到達性：複数タブの操作権の移転で、旧タブが共通一覧の表示中でも `returnToTitle()` が実行される。タイトル復帰では `forceResetModals({ skipBackgroundRecovery: true })` を通る。援軍拠点選択等でも強制リセット窓口を使用する。

## 再現と原因

`forceResetModals()` は全 `.modal` を `hidden` にするが、共通一覧の専門Viewの終了処理は `selectorModal.inert` の場合にしか呼ばなかった。普通に一覧が表示されている状態で強制終了すると、一覧DOM、仮想スクロールハンドラ、選択履歴・表示キャッシュ、遅延表示予約の所有者を破棄しない。通常終了の `UIInfoManager.closeCommonModal()` ではすでに解放できる。

## 変更

- `forceResetModals()` で全モーダルを非表示にし、旧描画予約を世代失効させた後、`UIInfoManager.closeCommonModal()` を一回呼ぶ。専門Viewの正規経路を利用し、残っていた `inert` 専用の部分解放を削除する。
- 強制復帰では通常地図がすでに復帰または解放された状態なので、同じ背景復旧や待機タイマーを追加しない。最後に旧 `selectorModal.inert` を戻して次の開き直しを妨げない。
- CSS、マスターデータ、数式、ゲームの意味判定は変更しない。
