# r879 国衆アイコン差替とクレジット更新

## 変更の根拠
- ユーザー提供の透過WebP国衆アイコンを採用。旧シルエット画像を削除し、表示箇所とロード時の先読みの両方を新画像へ向ける。
- 新画像の透明余白のみをトリミング（画素の加筆・色変更なし）し、城カードの国衆アイコン枠を18pxから22pxへ調整。拠点、国衆、ツールチップのロジックには手を加えない。
- ゲーム内クレジットの「シルエットイラスト（サニーサンデー）」およびURLを撤去し、見出し「生成AIの利用（プログラム・画像制作）」を「制作支援ツール（生成AI）」に変更。イラストAC、音源、効果音等の既存クレジットと規約・第三者ライセンスは維持。

## 更新ファイル
- 更新：`css/style.css`、`docs/audits/README.md`、`js/app_bootstrap.js`、`js/config.js`、`js/game.js`、`js/ui_map.js`、`tests/run_tests.js`
- 追加：`data/images/map/kunishu_icon.webp`、`docs/audits/r879_国衆アイコン差替とクレジット文言更新記録.md`
- 削除：`data/images/map/various_forces.webp`

## 確認
- 画像の存在、WebP形式、旧画像と旧参照の不在、先読み・表示参照の一致、CSSの縦横比維持を自動検査する。
- クレジットの静的出典と実モーダル表示の両方で見出し・提供元を検査する。
- 利用規約・第三者ライセンスの原文とゲームのバランス／戦闘処理／管理Excel・BINには変更を加えない。
