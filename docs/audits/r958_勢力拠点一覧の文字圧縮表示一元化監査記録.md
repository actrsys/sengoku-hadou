# r958 勢力・拠点一覧の文字圧縮表示一元化 — 構造監査

## 対象・適用規則

- 基準：r957完全版 `sengoku-hadou-main-r957-conversation-senior-family-rule-unification-complete.zip`。
- 現行 `ARCHITECTURE.md`（AUDIT-SCOPE、責務の正本、表示不変、配布検査）、`docs/manual/MAINTENANCE_POLICY.md`、`docs/manual/TECHNICAL_REFERENCE.md`（UIとファイル分割の禁則）を照合。
- 対象：`UIInfoManager` の勢力一覧と拠点一覧だけ。ゲームルール、判定、表示意匠、セーブ、シナリオは対象外。

## 発見と到達性

- `js/ui_info.js` の `_renderDaimyoList()` と `js/ui_info_kyoten.js` の `_renderKyotenList()` に、長い勢力名を同じ比率（0.05刻み、0.75下限）で縮小し、同じCSS変数とHTMLエスケープを返す無名関数が重複していた。
- 両関数はバイト単位で同一の本文で、いずれも同じ `UIInfoManager` インスタンスから通常の一覧操作で到達する。
- `index.html` では `ui_info.js` → `ui_info_kyoten.js` の順に読み込まれ、後者は `UIInfoManager.prototype` への既存拡張である。別Systemの依存関係を追加せず一元化できる。

## 改修

- `UIInfoManager._getCompressedInfoListTextHtml()` を唯一の正本として `js/ui_info.js` に設置。
- 勢力一覧と拠点一覧の局所関数2件を撤去し、従来の入力と閾値のまま共通メソッドを呼ぶ。
- 旧表示の計算式・戻り値・エスケープ方式は変えない。CSS、HTML、`UIManager._getCompressedTextHtml()`（別の表示文脈）は変更しない。
- r478の旧テストは重複実装の存在を要求していたため、実際のHTMLエスケープと共通窓口の呼び出し検証へ置換。r958の出力回帰テストを追加。
- 新ファイル、新System、新ラッパー、状態キャッシュは追加なし。未使用関数定義だけを除去。

## 回帰・設計監査

- 旧版の両コールバックが同一であることを確認し、旧関数と新共通メソッドを名称・文字数・HTML記号・閾値の**72,060条件で比較し、生成HTML文字列が完全一致**。
- `node tests/run_tests.js`：**1,528件成功・0件失敗・1件スキップ**。初回は旧テストのソース配置前提により1件失敗し、検査の目的を維持したままテストを修正して最終通過。
- `node tests/run_visual_tests.js`：終了コード0。PC・スマホ・低メモリ相当の既存画面回帰、一覧、会話、戦闘、年初月末通知が成功。
- `python tools/check_manual.py`：規則ID・参照リンク・原文保全すべてPASS。
- `python tools/verify_excel_bin_parity.py`：共通・1560・1570の管理Excel/BINが一致。
- `node tools/verify_release_sources.js`：主要数式（12,126 / 26,259 / 26,259件）の整合確認。
- `python tools/simulation/test_player_focus_sim.py`：4件成功。近似シミュレーター単体テストであり、実ゲームの長期再現ではない。
- r957とのZIP全項目・CRC・版番号・不要生成物の混入を検査。
