# A-148 家督譲渡候補の出生前混入と早期元服資格の一元化（r819）

## 実プレイでの到達経路

1560年「桶狭間」の初期化では、未登場武将の `status` は `unborn` になるが、武将の `isNotBorn` は初期年の途中では設定されない。プレイヤー家の家督譲渡メニューは `CommandCatalog` の `isSuccessorCandidate` と `CommandSystem.getBushoSelectorData('succession_target')` を通る。従来は出生前排除を `b.isNotBorn` のみに依存していたため、現行データを `DataManager` 相当の初期化・`FamilyLinker` で組み立てて実行すると、信長の家督譲渡候補に1565年生まれの織田勝長を含む**出生前年の一門16人**が混入した。

## 正本と改修

`LifeStatusRules` に `isBornByYear(person, year)` と `canAppearEarly(person, year)` を設け、未登場状態＋現在年までに出生していることを共通資格とした。`isNotBorn` は年初同期による派生フラグなので出生年の正本の代わりに使わない。

この資格を、家督譲渡の事前有効判定と候補一覧、大名・国主の死亡継承候補、諸勢力頭領の早期継承、謀反後の敗残一門の早期元服、遠山家の養子イベントの出生判定、武将肩書きの出生前・元服前表示へ適用。命令メニューと候補一覧の両方に `game.year` を渡して同一資格を使う。**予定所属・一門関係・継承順位・元服後の所属や拠点更新・イベント固有条件は従来の専門Systemが担当**し、共通Rulesには移さない。GameConfig の値・開始データ・確率・AI順位は変更していない。

## 検証と限界

- 改修前：1560年織田信長の家督譲渡で出生前の未登場一門16人が資格ありとなった（実データ／製品コードの候補判定を再現）。
- 改修後：`r819` の実データ回帰で出生前候補の混入がゼロ。出生年到達・出生前・死亡済み・登場済みも共通資格で区別し、表示と候補一覧を確認。
- r665の既存メニュー候補一致テストは、旧 `isNotBorn` 依存の期待値から出生年正本の期待値へ変更。旧型モックを使った継承テストは実 `constants.js` を読むよう修正した。
- ロジック試験：一時的に既存フォント4本を配置して実行し、全件成功を確認。配布にはフォント本体を同梱せず空の `data/fonts/` を残す。
- 長期自然観戦・プレイヤーによる全条件分岐の手動操作は未実施。
