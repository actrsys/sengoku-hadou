# r947 AI攻撃評価の勢力広域情報を月次作戦内だけで再利用 — 改修・設計・回帰監査

## 対象・実到達性

- 正本：r946 完全版 `sengoku-hadou-main-r946-ai-joraku-history-operation-local-reuse-complete.zip`。
- 実際の呼出経路：`AIOperationManager.generateOperation(clanId, legionId)` が同じ勢力・軍団の複数出撃元を順に評価し、同じ局所 `operationDecisionContext` を `AIEngine.decideAttackTarget()` へ渡す。
- 改修前：r946では上洛経路と過去所領集合は共有する一方、自家全拠点、奪われた拠点の勢力別件数、領有国／地方の統一状況、過去攻撃勢力、全領土と当該軍団の隣接勢力、当月大雪国の集合を出撃元ごとに作り直していた。
- これらは同じ作戦生成内で所有勢力、軍団、外交、地図・天候が変化しない月初立案処理のため、元と同じ判定式・集計順を保って再利用できる。`generateOperation()` の分割 `await` 後の世代・軍団有効性検査は従来どおり残す。別の軍団・次月の作戦・コンテキストのない直接評価には共有しない。

## 設計思想との照合と変更

- `ARCHITECTURE.md` の実到達性・短命な局所計算・状態正本・無用な互換層禁止、`docs/manual/TECHNICAL_REFERENCE.md` のAI改修必須ルールと「一連の行動で変化しない情報だけを共用」の規定に照合。
- `js/ai.js`：同じ `operationDecisionContext` に、従来の取得順・Setの挿入順を保った `myClanCastles`、`stolenCountsByClan`、`territoryAnalysis`、`heavySnowProvIds` を初回だけ記録。Setの本来の順序・厳密比較・二重所属の区別は変更しない。
- `territoryAnalysis` は、国／地方の領有・未統一状態、過去攻撃勢力、全領土および当該軍団の隣接勢力を一体として扱う。勢力の動的状態を永続化せず、計画をまたいだキャッシュは導入しない。
- 敵戦力と自己戦力の見積もり、候補ごとの評価、誤認乱数、同盟破棄・外交・スコア、兵数・兵糧は各出撃元について従来の順序で評価する。`AIOperationManager` の評価・`await`・作戦保存・乱数処理、計算Rules、画面・CSS・HTML、セーブ、シナリオ、管理Excel・BINは無変更。
- `js/config.js` の唯一の版正本を r947 へ更新。先行する単体テストの隣接勢力ブロック抽出境界だけを新構造に合わせ、検証する規則自体は維持。新たな回帰テストを追加した。

## 改修後のバグ的挙動・回帰検査

1. **直接実行比較**：r946 と r947 の `AIEngine.decideAttackTarget()` を独立したVM文脈でそれぞれ実行。将軍候補・外交・軍団・雪・敵配置・国・地方などを変えた1,500件（将軍候補あり750件）で、どちらにも同じ軍団ごとの局所作戦コンテキストと同じ擬似乱数を渡した。攻撃対象、得点、兵数、兵糧、乱数呼出回数は**1,500件すべて一致**。
2. 同比較の計測用getter呼出：`getCastle` 1,705,271回→1,108,522回、`getProvince` 587,020回→212,653回、`getClanCastles` 94,868回→82,871回。**作戦評価の合成テストにおける呼出回数であり、ゲーム全体の時間短縮率ではない。**
3. `tests/run_tests.js`：**1,514件成功、失敗0、スキップ1**。同一作戦の広域情報が同一参照で再利用され、所有者・大雪が変化した別作戦では再集計し、単発判断は共有しないことを実行検証。旧r945隣接集合テストも引き続き元と同順で一致。
4. `node tests/run_visual_tests.js`：**成功**。PC、スマホ、低メモリ相当の表示回帰、r943年初通知とr944月末死亡通知の空白paint検査を含む。
5. `python tools/check_manual.py`：規則ID・リンク・保護原文検査に成功。手順・設計上の新しい原則はないため正式マニュアルは改変しない。
6. `python tools/verify_excel_bin_parity.py`：共通、1560桶狭間、1570姉川のExcel/BIN完全一致。`node tools/verify_release_sources.js`：数式12,126＋26,259＋26,259件成功。
7. `python tools/simulation/test_player_focus_sim.py`：補助シミュレータ4件成功。これは本体の長時間自然観戦そのものではない。
8. 低性能スマホ**実機**での長時間観戦や、全史実イベント分岐の自然経過の完全な新旧同一性は未検証。合成比較での一致をその範囲以上に拡大解釈しない。
