# r951 AI拠点ターンの固定30ms起動待機撤去 — 改修・設計・回帰監査

## 1. 監査対象・実際の到達経路

- 元版：ChatGPTライブラリのr950完全版 `sengoku-hadou-main-r950-ai-diplomacy-frontier-single-read-complete.zip`。
- 対象：`TurnManager.processTurn()` → `_scheduleAITurn(castle)` → `AIEngine.execAI(castle)`。他勢力・委任拠点の未行動ターンで毎回到達する。
- 改修前はAIガード公開と進捗表示の直後、**全AI拠点に一律30msのタイマー**を予約していた。`AIEngine.execAI()` の冒頭には別途 `setTimeout(0)` の制御譲渡がある。月初の全国作戦・四半期人事・戦闘の分割待機とは独立している。
- 30msはAI判断や戦争計算の必要条件ではなく、予約後にも既存のターン世代、年月、キュー位置、対象拠点参照、戦闘開始の検査が実行される。

## 2. 改修と設計監査

- `js/turn_manager.js`：`_scheduleAITurn()` のタイマー予約を30msから0msへ変更。予約を同期実行にはせず、イベントループへの制御譲渡を維持。不要になった局所 `delay` 変数は削除した。
- AIガード表示・進捗更新の順序とDOM、冒頭の `AIEngine.execAI()` 0ms待機、通常ターンの0ms継続予約、スマホ軽量モード、戦闘の待機・演出、プレイヤーターンの開始確認、月末の300ms表示、ロード・タイトル・別タブによる失効を変更していない。
- 正本は従来どおり `TurnManager` と `AIEngine`。新しいタイマー管理、キャッシュ、二重キュー、保険用の遅延、互換ラッパーを追加していない。
- `ARCHITECTURE.md` の実到達性・無駄な固定待機を増やさない方針、責務分離、PC/スマホのガード/ロード幕引渡し、`docs/manual/TECHNICAL_REFERENCE.md` のAI世代失効・非同期処理分割を照合。時間短縮は演出内容や計算結果の変更を必要としない。最新の仕様条文に変更がないためマニュアル本文は更新しない。

## 3. 改修前後の比較とバグ的挙動検査

1. **実製品のTurnManager予約処理＋合成AI処理**（Node.js v22.16.0、同一環境、実体TurnManager・モック化した0msのAI内部待機）で、拠点10件：314.13ms→22.81ms、40件：1,254.46ms→89.03ms、100件：3,133.65ms→219.27ms。各拠点の起動順・ガードの公開・進捗呼出回数が一致。**AI思考/戦争/外交本体を含む月全体の短縮率ではない。**
2. **Chromium実ブラウザで実製品のTurnManager予約処理を使用**し、50拠点の連続処理をPC(1280×720)・スマホ(390×844)で旧版/新版比較。PC：1,709ms→393ms、スマホ：1,710ms→393ms。描画監視の記録は旧PC103/新PC23フレーム、旧スマホ102/新スマホ23フレームで、各条件とも**AIガード表示フレームあり、空白フレーム0、最終進捗50/50**。処理が速くなる分、途中の進捗番号が実際に描かれるフレーム数は少なくなる。UIのDOM構造と見た目の定義は無変更。これは合成AI処理であり、実ゲームの長時間観戦ではない。
3. `node tests/run_tests.js`：**1,519件成功、0件失敗、1件スキップ**。追加テストは予約が同期実行されないこと、ガードと進捗更新が予約に先行すること、戦闘開始後の予約無効化、世代中断後の旧予約無効化を確認。既存の月跨ぎ、イベント待機、AI実行例外、外交・戦争・内政の回帰検査も通過。
4. `node tests/run_visual_tests.js`：既存のPC・スマホ・低メモリ画面の回帰を通過。r943年初通知、r944月末死亡通知、外交・戦闘・一覧の会話引渡しと空白paint防止を含む。
5. `python tools/check_manual.py`：規則ID・リンク・旧マニュアル原文保全などPASS。
6. `python tools/verify_excel_bin_parity.py`：共通・1560桶狭間・1570姉川のExcelとBINが一致。`node tools/verify_release_sources.js`：主要数式12,126＋26,259＋26,259件の検査成功。
7. `python tools/simulation/test_player_focus_sim.py`：4件成功。近似シミュレーションであり、本体長時間自然観戦ではない。フォント実体に依存する検査は配布仕様により1件スキップ。

## 4. 継続事項・検証範囲の限界

- **ゲームルール・AIの計算処理・乱数コード・シナリオマスター・CSS・HTML・セーブ形式・戦闘の固定待機は変更なし。** 変更は予約時刻のみであり、AIが処理されるカレンダー上の拠点順も従来どおり。
- 処理が早まると、AI進捗の中間表示を実際に見る時間は短くなるが、ガードの継続表示と画面の空白防止は確認した。
- 古いスマートフォン実機での長時間自然観戦、すべてのプレイヤー・AI戦争組合せ、連続月でのFPS・消費電力・メモリ変動、乱数を固定したゲーム本体フルシミュレーションは未実施。現時点で確認された不具合とは区別する。
