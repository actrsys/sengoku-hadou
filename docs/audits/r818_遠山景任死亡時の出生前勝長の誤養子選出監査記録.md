# A-147 遠山景任死亡イベントの織田勝長出生前判定（r818）

## 到達経路と原因

`historical_toyama_takeover` は `busho_death` 時に起動し、遠山景任が大名で織田信長へ従属している場合、織田勝長を養子にして城主へ迎える。1560年「桶狭間」開始データでは遠山家→織田家の外交状態がすでに「従属」。景任は大名として現役で、勝長は**1565年生まれ・1577年登場予定**である。

武将の初期化 `DataManager.joinData()` は勝長の `status` を `unborn` にするが、武将の `isNotBorn` は初期年の途中では設定しない。出生前フラグの同期は `LifeSystem._syncPreBirthStatus()` が年初に行う。従来イベントは `unborn && isNotBorn` だけを除外していたため、開始年1560年の時点で勝長を出生済みとして条件成立と判定した。野戦で大名が負傷し `deathFlag` が立ち、月次の死亡判定に通る経路は通常のゲーム処理に存在する。実際の長期観戦で当該条件が同時成立した回数は測定していない。

## 再現・最小修正

現行マスターと1560年・1570年の両シナリオBINから関係・生年・登場年・初期当主を読み、製品版 `GameEvents` の条件判定を実行した。新規回帰を加えた**修正前のr817**は、1560年の勝長（未登場、`isNotBorn` 未設定、出生前）で誤って `true` を返した。1570年は出生済みで元服前のため、従来どおり `true` が正しい。

`EventCheck` の歴史イベント固有の成立条件に `birthYear > game.year` の確認を加え、従来の `isNotBorn` 判定も維持した。`LifeSystem` が管理する生死・登場状態と `AffiliationSystem` が管理する元服後の活動状態・転任・城主任命の責務は変更していない。元服年、養子・当主吸収・忠誠・城主のゲームルールも変更せず、出生前にだけイベントを拒否する。

## 回帰・検査

- 修正前：新規1件失敗（1560年は不成立であるべきところ成立）。配布仕様によるフォント実体検査の既知失敗を除き、その他既存検査は成功。
- 修正後：開始年1560年では不成立、出生済みの1570年では従来どおり成立。ロジック **1,335件成功・失敗0件**（検査時に既存フォントを一時配置）。
- 現行マニュアル検査、管理ExcelとBIN一致・主要数式、近似シミュレーション4件、PC・スマホ・低メモリスマホ表示回帰は合格。
- 長期自然観戦でこの事件の発生頻度・全分岐を検証したものではない。
