# r726 面談途中の年長親族二人称呼称監査（A-046）

## 症状・到達性
- r725では面談の初回挨拶に用いる呼称と、その後の「他者について」で聞き手の当主を指す呼称に同じ `_getDirectAddressName()` を用いていた。父・祖父・伯父が年少当主へ話すと、挨拶で「信長か」と呼んだ後の所見も「信長の考えには…」と固有名を繰り返す。
- `InterviewSystem.executeInterviewTopic()` → `_getTargetLoyaltyAssessment()` → `_applyDirectAddress()` の本番経路で確認。調子返答も同じ後続会話の呼称変換を通る。
- UIで実際に到達する会話内容の違和感に対する表現変更であり、忠誠等のゲーム進行に影響する不具合ではない。

## 方針・変更範囲
- 最初の挨拶は相手を識別する姓名／官位を保持する。途中では話者の人物関係正本 `getInterviewSpeakerPosture()` が `senior_close` / `senior_extended` の場合だけ、聞き手当主への直接言及を「おぬし」に揃える。
- 既存の `_applyDirectAddress()` の `殿` 部分に限って差し替え、当主の固有名を会話全体で置換しない。話題の第三者には既存 `getInterviewTargetCallName()` 等の独立した呼称が適用され、官位・尊敬表現は保持する。
- 通常家臣の「殿」、子・弟・孫側から年長親族への「父上」等、公的な高格式者の呼称は変更しない。新たな表示状態・人物関係キャッシュ・専用会話エンジンは追加しない。

## 再現と検証
- r725の製品コードに追加した同一テストを適用すると1,200件成功・4件失敗。既存の3件は「信長の考え」を期待する旧仕様であり、新仕様の「おぬしの考え」になっていないことを検出。追加の1件は初回挨拶／途中本文の呼称分離を検出。
- r726では全ロジックテスト1,204件成功・失敗0件。父・祖父・伯父の冒頭挨拶を名で維持し、途中は「おぬし」を使用する。第三者への「おられる」、通常家臣の「殿」、年少者→父の「父上」の回帰も成功。
- `node tests/run_visual_tests.js`：PC・スマホ・低メモリスマホを含む表示回帰成功。
- `node tools/verify_release_sources.js`：共通・1560年・1570年の管理Excel/BIN/数式検査成功。
- `python tools/verify_excel_bin_parity.py`：3組一致。
- `python tools/simulation/test_player_focus_sim.py`：4件成功。ただしこのシミュレーションはJS実行全体を再現するE2Eではない。

## 改修後の設計監査・限界
- 会話の直接呼称、第三者への言及、話者の文末レジスターの既存責務分離を維持。話者姿勢の正本や面談の態度・台詞数は変更しない。
- 全武将・全シナリオの長期自然プレイ、すべての台詞を人手で確認する網羅検証は未実施。
