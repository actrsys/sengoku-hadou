# r925 強制画面リセット時の面談・国主評定の一時状態解放

- 正本：ChatGPTライブラリ `/sengoku-hadou-main-r924-forced-modal-reset-cleanup-complete.zip`、内部版 `r924`。旧版は変更せず新完全版 `r925` を作成。
- 監査範囲：`UIManager.forceResetModals()`、`InterviewView.close()`／`_clearView()`、`LegionCouncilView.close()` と席・命令編集画面、操作権移転時の `UIManager.returnToTitle()`。
- 設計方針：現行 `ARCHITECTURE.md` の実到達性、専門Viewによる参照解放、不要な背景復帰・タイマー追加の禁止、修正前後の再現、旧CSS・画像・計算値保持を優先。

## 1. 再現・重要度

**中（終了後の不要な参照・画像DOM保持）**。

別タブが操作権を取得すると、旧タブは面談や国主評定を開いている途中でも `returnToTitle()` → `forceResetModals({ skipBackgroundRecovery: true })` に到達する。r924では共通一覧だけ専門の `closeCommonModal()` を呼んでいた。強制リセットは `.modal` を非表示にするが、面談の `pageItems`・`currentSpeaker`・`onPageItemSelect`・画面送りのクリックlistenerと、評定の `members`・編集中方針・編集モードが専用Viewに残る。通常終了経路では既に対応する解放が存在したが、非表示後にその経路を呼んでいない。

修正前のr924実コードを使う回帰テストでは、強制リセット後も面談の人物配列と評定の一時編集データが残り、**1,486成功／1失敗／1スキップ**となった。これは実際に到達可能なタイトル復帰経路を使うテストであるが、複数タブ実機による長時間のメモリ計測ではない。

## 2. 修正

- 強制リセットでは全モーダルを隠した後、`InterviewView.close({ forceReset: true })`、`LegionCouncilView.close({ forceReset: true })` を呼ぶ。専門Viewが自身の一時状態を解放し、**背景Canvasの復帰・2paint待機は新たに起動しない**。
- 面談は通常の `_clearView()` を利用し、終了後に旧話者の情報DOM（顔画像・属性）の参照も消す。旧クリックlistenerを除去し、ページ候補とコールバックを破棄する。
- 評定は既存の `close()` の確定状態リセットを共有し、終了後の席・命令編集のDOMも解放する。結果画面への引継ぎと通常終了の順序は変えない。
- CSS・画像・管理Excel・BIN・ゲームルール・セーブ形式・画面意匠・固定タイマーは不変更。
