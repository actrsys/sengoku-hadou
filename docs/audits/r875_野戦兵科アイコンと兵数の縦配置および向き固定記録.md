# r875 野戦兵科アイコン・兵数の縦配置と回転分離

## 変更の対象・根拠
- r874で導入した透過カラー兵科アイコンは、従来の数値と横並びの縮小枠内にあり、枠線と背景色が残っていた。
- 利用者の指示に従い、野戦の凸（部隊本体）の向きとは無関係に、兵科画像を兵数の真上へ中央揃えで固定する。
- `js/field_war.js` ではもともと `.fw-unit-icon`（回転する凸）と `.fw-unit-status-wrap`（兵科画像・兵数）が兄弟要素であり、回転処理は本体にのみ適用される。DOMやターン更新処理を増やさずCSSだけで変更する。

## 修正点
- `css/style.css`：`.fw-unit-status-wrap` の横並び・0.45倍縮小を廃止し、凸の中央下端に固定した縦並びに変更。アイコンの背景色・枠線・角丸を撤去。透過カラーWebPの `contain` 表示を維持し、兵数を中央揃えにする。
- `tests/run_tests.js`：兵科画像が兵数より前にあるDOM、凸とは別レイヤー、枠線・背景なし、固定縦並びの契約を検査。
- `tests/run_visual_tests.js`：PC・スマホ、兵科3種、6方向、通常部隊と移動プレビューの各パターンで、画像と数値の位置が向き変更で動かず、アイコンが数値の上にあり、枠線・背景がないことをブラウザの矩形・computed styleで確認。
- 兵科画像・戦闘計算・AIロジック・規約・クレジット・管理データは変更しない。

## 検証
- 修正前のr874に追加したロジックテストだけが失敗し、修正後は `1420 passed, 0 failed, 1 skipped`。
- 実ブラウザのPC・スマホ双方で、3兵科×6方向×通常／プレビューの固定表示検査に成功。既存画面回帰も成功。
- 異なる兵数に対応する凸のサイズ（16・24・31px）で検査。アイコン画像は24pxの表示枠に `contain` で収める。
- 検証用HTML、スクリーンショット、Pythonキャッシュは配布ZIPへ含めない。
