- **監査範囲**：`UIManager.showResultModal()`、`closeResultModal()`、`forceResetModals()`、`returnToTitle()` の結果画面表示・終了・強制タイトル復帰。既存の共通モーダル引継ぎ、専用View終了処理、データ・CSSの正本も照合。
- **設計根拠**：`ARCHITECTURE.md` の実ゲーム到達性、状態の正本、旧処理上書き禁止、最小改修、無意味な監視器追加禁止。既存のr904/r911/r916/r920/r924/r931の引継ぎ・強制終了契約を維持。

## 再現と原因

**重要度：中（旧シナリオの結果・外交後続処理を閉包に保持し続ける）**。

実ゲームで、外交結果などを表示した状態で別タブへ操作権が移転すると、旧タブの `returnToTitle()` → `forceResetModals()` に到達できる。結果画面は非表示になるが、画面の確認後処理を参照する `onResultModalClose` と、後続会話に引き渡す `resultFollowupDialogHandoff` は初期化されていなかった。このため、結果画面を次に開くまで旧ゲームの人物・処遇結果などを参照するクロージャを保持する。**旧処理が自動実行されるとは確認していない**。不要な参照保持が問題であり、見た目や戦争計算の不具合と混同しない。

## 変更

- `UIManager.forceResetModals()` が画面の終了予約・結果終了フラグを失効させる箇所で、`onResultModalClose = null` と `resultFollowupDialogHandoff = false` を確定。
- **強制終了で旧コールバックを実行しない**。通常の結果画面の閉じる操作・会話への引継ぎ・背景復帰paint待ちは既存処理を変更しない。
- 新しいタイマー・監視器・CSS・互換処理は追加しない。セーブ形式・ゲームルール・画像・マスターデータは無変更。
