# r821 1570年「姉川」死亡済み武将の官位一括除去

## 修正理由

r820では死亡者を史実イベントの現在の官位保持者検索から除外したが、元の1570年シナリオには死亡済みの武将の官位が残存していた。ユーザー指示により、イベント側の例外で吸収するだけでなく、開始データそのものを修正する。

## 対象と判定

- 対象: 1570年「姉川」の `warriors_state.courtRank`。共通武将マスターの `endYear < 1570`、またはダミー `startYear == 9999` を開始時死亡とする実装規則に合わせる。
- 13人: 今川義元(1004009)、田向重継(1010015)、田向重治(1010019)、足利義藤(1017003)、三好長慶(1020005)、安宅冬康(1020011)、十河一存(1020013)、武田元栄(1038004)、山名豊通(1039006)、山名豊定(1039012)、尼子晴久(1043004)、西園寺実充(1051002)、浪岡具統(1069009)。
- 義藤の `1|25` は一部だけでなく両方削除する。1570年没の武将は開始時生存のため対象外。
- 1560年シナリオ・共通マスター・生存者の官位・その他のシナリオデータは変更しない。

## 正本と専門責務

管理Excel `管理用Excel/1570_anegawa.xlsm` の官位列を編集し、同内容を `data/scenarios/1570_anegawa/scenario.bin` へ反映。既存の数式・参照列・シート構造を保存した。`LifeStatusRules` と `EventCheck` の死亡者・未登場者を現在の官位保持者と誤認しない共通判定（r820）は維持する。今後の初期官位修正でも、イベントへの個別回避条件でデータの不整合を隠さない。

## 検証

- 1570年全武将と共通マスターの死亡年を照合し、官位残存13件を修正。
- Excelの更新は13個の `courtRank` セルのみ。他セル、数式、XML、マクロなどは変更なし。
- 回帰テスト: 死亡者の官位ゼロ、足利義昭・上杉謙信の官位維持、r820の現役将軍検索。
- 実ブラウザ長期自然観戦での全分岐網羅は未実施。
