# r874 野戦兵科カラーアイコン差替と未使用歯車削除

## 目的と到達経路
- 野戦中の部隊アイコン下部に表示する足軽・騎馬・鉄砲の兵科アイコンを、ユーザー提供の透過WebPへ置換した。
- 旧CSSでは各兵科画像を `mask-image` と白色背景で単色シルエット化していたため、カラー画像をそのまま置いただけでは配色が失われる。既存の `fw-troop-icon` の擬似要素を透過カラー画像の `background-image` へ切り替え、枠を14pxから24pxへ調整し、`contain` で縦横比を保持する。部隊の重心・戦闘ロジック・兵科識別値は変更しない。
- 未使用の歯車画像 `gear_icon.webp` とゲーム開始時の先読み参照を撤去した。兵科3種の先読みは維持する。
- 旧兵科素材の提供元である `ICOOON MONO` のクレジット行を削除した。ほかの画像・音素材提供元の表示と利用規約・第三者ライセンスは維持した。

## 変更ファイル
- 更新：`css/style.css`、`data/images/icon/ashigaru.webp`、`data/images/icon/kiba.webp`、`data/images/icon/teppo.webp`、`docs/audits/README.md`、`js/app_bootstrap.js`、`js/config.js`、`js/game.js`、`tests/run_tests.js`
- 追加：`docs/audits/r874_野戦兵科カラーアイコン差替と未使用歯車削除記録.md`
- 削除：`data/images/icon/gear_icon.webp`

## 検査方針・範囲
- 新規回帰テストは、3種のWebPの存在・256×256の拡張WebPヘッダ、通常先読みの維持、カラー描画CSS、削除した歯車とクレジットの不在を検査する。
- 変更前には同じテストが失敗し、変更後に通過した。元画像の表示内容を機械的に認識するテストではない。
- 戦闘の数値・AI判断、管理ExcelとBIN、外部素材の個別ライセンス原文は無変更。
