# r949 AI月初不満判定の最小敵威信局所共有 — 改修・設計・回帰監査

## 1. 監査対象と実到達経路

- 元版：ChatGPTライブラリのr948完全版 `sengoku-hadou-main-r948-ai-monthly-diplomacy-adjacency-reuse-complete.zip`。
- `AIOperationManager.processMonthlyOperations()` → `decreaseSentimentForHighTension()` → `thinkMonthlyDiplomacy()`。毎月、存続する非プレイヤー大名家で通る。
- 同盟・支配の相手で `sentiment >= 50`、非史実固定の関係が複数あると、旧実装では**対象ごと**に同じ隣接勢力を全件走査し、同盟・主従でない隣接勢力の最小威信を再集計していた。
- 不満判定で変更するのは特殊関係の友好度だけ。`DiplomacyManager.updateSentiment()` は同盟・主従などの特殊状態を友好度閾値によって変更しない。対象とされる隣接拠点所有者、兵力、威信計算に使う資源・官位はこの判定では変化しない。

## 2. 最小改修と設計整合

- 既存 `js/ai_operation.js` の `decreaseSentimentForHighTension()` 内で、比較に使う最小敵威信を**最初に必要になった時だけ**計算し、同一呼出中の後続の保護対象へ再利用する。
- 必要な対象がないときは走査しない。外側の隣接勢力の順序、各対象の外交関係・友好度・イベント保護確認、相手威信取得、友好度変更の実行順、数式・乱数・変更量は維持。各月・各大名家・単独呼出の次回は再集計する。
- `GameManager.updateClanPrestige()` は勢力の兵力・資源・収入と官位から計算され、当該友好度変更では変化しない。初回に必要な勢力だけ更新する既存 `AIEngine.getClanPrestige()` の責務は移さず、結果の短期再利用に限る。
- 新しいファイル／共通の永続キャッシュ／追加の旧互換処理／別の判定式は作らない。画面・ゲームデータ・セーブ形式・既存の分割待機は不変。
- `ARCHITECTURE.md` の実到達性・無益な改修禁止・専門部署の状態正本・AI判断・乱数・見た目の不変条件、`docs/manual/TECHNICAL_REFERENCE.md` の「AI改修時の必須ルール」及びマニュアル運用規約を照合。新しい設計規則がないためマニュアル本文は無変更。

## 3. 検証結果

1. r948とr949を独立したJavaScript VM上で比較。隣接0～30勢力、関係の種類、イベント保護、友好度、威信、当主義理、重複接続を変えた**3,600ケース**で、月初不満判定と後続外交判断の**友好度・更新順・候補順・選択結果**が全件一致。比較環境で実際の友好度変更は計3,753回。
2. 上記合成環境で、威信取得は **132,934→96,027回**、外交関係取得は **281,582→211,782回**。こちらは不満判定と外交計画の比較用環境での計測値であり、実ゲーム全体の高速化率ではない。威信の初回更新処理と再使用の違いを区別する。
3. `node tests/run_tests.js`：**1,516件成功・0件失敗・1件スキップ**。新規回帰では、複数の保護対象における敵威信の一回計算、友好度更新順、次の呼出での最新威信再取得を確認。
4. `node tests/run_visual_tests.js`：成功。PC・スマホ・低メモリ相当の主要画面、年初・月末の連続通知と外交・戦争画面の既存描画回帰が成功。
5. `python tools/check_manual.py`：規則ID・参照リンク・旧原文保全の検査成功。
6. `python tools/verify_excel_bin_parity.py`：共通、1560桶狭間、1570姉川の管理Excel/BIN完全一致。`node tools/verify_release_sources.js`：数式検査12,126＋26,259＋26,259件成功。
7. `python tools/simulation/test_player_focus_sim.py`：補助シミュレーション4件成功。ただし実ゲーム本体の長時間観戦とは別物。
8. フォント実体検査は配布仕様どおり1件スキップ。旧型スマホ実機の長時間自然観戦、あらゆる外交分岐が自然発生する月次連続プレイについては未検証。

## 4. 不具合・副作用の判断

- 改修後の比較範囲で通知、外交結果、判定順・友好度更新、表示に新たな異常は確認されなかった。
- 最小威信の有効期間は同一 `decreaseSentimentForHighTension()` 呼出内のみ。外交関係が更新される次の独立した処理まで保持しないため、将来の分岐を先読みする変更ではない。
