# r953 四半期AI人事の固定分割待機を時間予算化 — 改修・監査記録

## 監査対象・実到達性

- 正本：ChatGPTライブラリ `sengoku-hadou-main-r952-ai-monthly-budgeted-yield-complete.zip`。
- 実行経路：`TurnManager.startMonth()` → `AIStaffing.processQuarterlyStaffing()`。1・4・7・10月のみ、現役AI勢力について大名居城移転と軍団新設・解散を実行する。
- r952の人事は対象勢力4家ごとに常に `setTimeout(0)` で処理を分割していた。計算が軽い4家にもタイマーが積み重なる一方、重い4家が続いた場合も途中に追加の譲渡はない。

## 改修内容・設計判断

- `js/ai_staffing.js` の **四半期人事の分割境界のみ**変更。最初の4勢力後の制御譲渡は維持し、以後は直前の分割からのCPU/経過時間が約8msに達した時点だけ `setTimeout(0)` を挟む。
- 時刻取得は `performance.now()` を正とし、存在しない軽量環境のみ `Date.now()` を使用。タイマー・時刻変数は当該メソッドのローカル変数で、ゲーム状態、保存内容、他月には残さない。
- 大名移転・軍団新設/解散の実行順、10回の再試行上限、対象勢力の判定、ゲームルール、乱数の呼出位置、ログ発行順、次月の処理を変更しない。分割待機後のTurnManager世代・年月検査も維持。
- `ARCHITECTURE.md` および `docs/manual/TECHNICAL_REFERENCE.md` の実到達性／処理分割／低性能端末への負荷配慮／不要な固定待機の削減／専門部署責務の規則に照合。ルール自体に変更なし。新たな管理System、永続キャッシュ、別系統の画面制御は追加しない。
