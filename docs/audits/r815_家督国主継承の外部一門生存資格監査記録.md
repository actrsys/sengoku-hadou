# A-144 大名・国主の外部一門候補における生存資格（r815）

## 実ゲームの到達性と再現

`LifeSystem.executeDeath()` から大名家督・国主継承を判定する通常の経路に、`LifeSystem._collectSuccessionCandidates()` がある。AI勢力の外部一門探索では「浪人か、諸勢力所属か」を条件にする一方、諸勢力所属者の `status` を確認していなかった。死亡・未登場の人物にも予定／旧所属 `belongKunishuId` が残るため、生存していない一門が家督・国主の後任候補になった。

1570年「姉川」の初期データで、足利家当主・一乗院覚慶（ID 1017004）の候補に、1568年死亡済みで阿波足利家の所属ID 48を保持する足利義栄（ID 1017006）が唯一選ばれることを実際の `LifeSystem` と `FamilyLinker` で再現した。死亡後の継承経路そのものが自然死・戦死で到達可能。長期自然観戦で覚慶の死亡まで観測したものではなく、実シナリオデータと本体候補選出による再現である。

同じ欠落により、諸勢力所属予定の出生前武将も外部一門候補となり得た。また、出生済みだが未登場の一門は、正規の早期元服候補と外部一門候補の両方に重複して入っていた。

## 最小改修と責務

既存の `LifeSystem._collectSuccessionCandidates()` に限定し、浪人一門は従来どおり許容し、諸勢力から迎える外部一門は `BushoStatusRules.isActive()` に合格する現役構成員だけを対象とした。死亡者・未登場者を外部一門経由で選ばない。出生済み未登場の一門は従来の `unbornFamily`（出生年と `isNotBorn` をチェック）でのみ扱う。大名と国主の比較順位、AIとプレイヤーの選択方法、諸勢力内部の継承資格、所属変更・城主更新の担当Systemは変更していない。

## 回帰

追加3件はr814で全件失敗し、修正後に全件成功した。家督死亡者混入、国主死亡者混入と同軍団家臣へのフォールバック、現役諸勢力一門・浪人・出生済み未登場の資格をそれぞれ確認する。実データの1570年足利家で修正後は細川藤孝・和田惟政ら現役家臣が候補になった。管理Excel・BINを変更していない。
