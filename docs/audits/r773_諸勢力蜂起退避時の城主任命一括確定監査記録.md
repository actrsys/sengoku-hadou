# r773 諸勢力蜂起の退避中に発生する仮城主任命（A-099）

## 到達可能性と原因

諸勢力が蜂起して通常大名家の拠点を制圧する既存の戦争決着経路では、旧所有家の武将を各人ごとに逃亡先へ移動する。旧拠点を中立化した後でも、逃亡先の城主更新は `AffiliationSystem.moveCastle()` ごとに即時実施され、先に家臣が着任し後から大名が着任した場合、先着者が短時間だけ城主に就いて正式な【城主任命】履歴が残っていた。通常ゲームでは無城主の自領拠点が許容されるので到達可能である。

1560年南部家の実在城・武将IDを用い、三戸城から石川城へ先に家臣、後で当主が退避し、退避先の城主が不在という有効な進行状態を再現。修正前は既存1260件成功、追加1件失敗（途中の仮城主任命1件）。

## 修正

諸勢力蜂起の決着処理で、各武将の逃亡先抽選・`handleDaimyoEscape` の個別処遇は変更せず、`moveCastle()` の既存 `deferCastleLordUpdate` / `deferUI` オプションで処理中の任命を保留。すべての退避完了後に移動先を重複なしで走査し、`AffiliationSystem.updateCastleLord()` を一度ずつ呼んで正式な城主を確定し、UIを一度更新する。異なる逃亡先を持つ武将を誤って同一拠点にまとめない。履歴の削除・新状態管理・新APIは追加しない。

## 回帰・限界

修正後の `node tests/run_tests.js` は1261件成功・失敗0件。実データと本体の `AffiliationSystem` を用いた通常の蜂起退避ブロックの回帰を追加。武将の最終所在地と当主の城主就任、仮任命履歴の不存在を確認した。元の家臣所属・退避先抽選確率・勝敗条件は変えていない。

実ブラウザでの自然発生する蜂起から終戦までの長期観戦網羅は未実施。
