# r783 指南書の内部用語・プレイヤー視点の説明監査

## 指摘と範囲

ユーザーから、指南書の「生成頭領以外の武将が全員いなくなった場合」はプレイヤーには存在しない区分であるため、単に「武将が全員いなくなった場合」と表現するよう指示を受けた。他の指南書の記事とコマンド説明も全文点検し、表示文面に残った内部・開発視点の語を調べた。

## 改善内容

- ゲームオーバーの記述を「自分の大名家が滅亡すると…」および「1700年1月を迎えるか、武将が全員いなくなった場合…」とし、内部の生成頭領の例外を本文へ出さない。**ゲーム終了の実際の判定・将来登場予定者の扱いは変更しない**。
- 「操作をAIへ任せる」は、観戦で何ができるかを直接説明する「自分で命令を出さずに、各勢力の動きを眺める／観戦する」に変更した（記事と個別コマンドの両方）。
- 「入れ子の項目／ボタン」「全勢力の処理」「各種判定」は、命令の選び方・各家の行動・月替わりに見られる変化を表す自然な説明へ変更。
- 表示上のコマンド名・設定名（通常／軽量など）、歴史用語、戦闘ルール、確率・非公開値の保護は維持。
- 現行マニュアルの指南書の条文へ「内部管理用語をプレイヤーへ見せない」方針を統合。重複した新条文・新責務は作らない。
- `tests/run_tests.js` へ、コメントではなく実際の指南書データを読み込んでプレイヤー向けの語を検査する回帰テストを追加。

## 影響範囲

指南書本文（`js/guide_data.js`）と設計方針・テスト・版番号・監査索引のみ変更。`EndingSystem` の終了条件、ゲーム進行、セーブ・マスター・管理Excel／BIN、UIレイアウト・ゲームバランスには変更なし。

- `node tests/run_tests.js`：**1,271 passed / 0 failed**。新規テストは表示対象の記事・全コマンド説明等を実際にロードし、内部表現の残存、年限の欠落、観戦案内の誤記を検査。
- `python tools/check_manual.py`：**PASS**。規則ID・マニュアルリンク・旧マニュアル原文保全を確認。
- `node tools/verify_release_sources.js`：**PASS**。共通・1560・1570の管理Excel／BIN・主要数式を照合（管理データは無変更）。
- `python tools/simulation/test_player_focus_sim.py`：**4件成功、失敗0件**（近似シミュレーターの単体検査）。
- `node tests/run_visual_tests.js`：**PASS**。PC・スマホ・低メモリスマホの指南書、固定画面、既存画面を実ブラウザで確認。
- 検証環境ではr780由来の変更のないフォント4ファイルのSHA-256を照合して補完した。r782のフォント省略版のままでは、旧テスト中のフォント存在検査だけがエラーになるため、本来の配布状態へ補完した後に全検査を完了した。
