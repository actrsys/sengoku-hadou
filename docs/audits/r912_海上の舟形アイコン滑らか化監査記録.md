# r912 海上の舟形アイコン滑らか化監査記録

- 対象: 野戦の海上用舟形アイコン一式 (`data/images/field_war_images/ship_*.webp`)
- 背景: 既存の舟形アイコンはドット形状由来で輪郭の段差が目立ち、海戦表示でぎざぎざに見える。
- 方針: 色分け・識別性・透過前提は維持しつつ、舟形シルエットと影を滑らかな曲線で描き直す。ロジックや表示サイズは変更しない。
- 実施内容:
  - 攻撃/防御/援軍/自軍援軍/総大将を含む舟形アイコン12枚を滑らかな曲線シルエットへ差し替え。
  - 通常枠は従来どおり各陣営色よりやや濃い外枠、総大将版は白枠を維持。
  - 最外周の黒線と `ship_shadow.webp` も新シルエットに合わせて再生成。
- 影響範囲: 画像差し替えのみ。野戦計算、UI配置、当たり判定、読み込み経路は変更なし。
- 確認:
  - 画像名・パスの互換性を維持。
  - 透過WebPとして保存。
  - 海上用画像以外は無変更。
