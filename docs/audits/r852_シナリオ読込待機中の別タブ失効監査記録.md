# r852 シナリオ読込待機中の別タブ失効と画面公開防止

## 正本と実際の到達経路

- 基準はライブラリの `sengoku-hadou-main-r851-fonts-folder-empty.zip`。現行の `ARCHITECTURE.md`、`docs/manual/MAINTENANCE_POLICY.md`、`docs/manual/TECHNICAL_REFERENCE.md`、r850・r851監査と `GameManager.startNewGame()` / `loadScenario()` を確認した。
- 通常操作で旧タブAが「はじめから」を押してシナリオ一覧を待っている間、同一オリジンの別タブBでゲームを開始できる。Bの `TabSessionCoordinator.claim()` は共有localStorageの操作権を更新する。
- 背景タブの `storage` 通知が遅延し、Aの `DataManager.loadScenarioDefinitions()` の完了が先に来る場合、r851の `isStartFlowLatest()` は旧タブ内のターン世代だけを検査し、Aのシナリオ選択画面を公開していた。`loadScenario()` の画像描画待機やデータ読込にも同じ判定の欠落があった。
- 操作権の実際の奪取は製品の `TabSessionCoordinator` と共有localStorageを用い、通知だけを遅延させた。未登場武将や破損セーブの人工状態変更とは異なる、ブラウザの通常の非同期実行順序の競合である。

## 修正前再現・修正範囲

- 新規回帰試験は修正前に **失敗**：Aのメニュー取得Promise待機中、Bが操作権を取得したにもかかわらず、Aの `showScenarioSelection()` が1回呼ばれた。
- `js/game.js` の `isStartFlowLatest()` と `isScenarioLoadLatest()` に、同じ `TabSessionCoordinator.isOwner()` を組み合わせた。既存の各非同期待機後と進捗通知のガードを再利用し、新しい正本や独自中断処理は追加しない。
- 失効通知が届いた後のタイトル復帰は引き続き既存の `TabSessionCoordinator.onLost` → `UIManager.returnToTitle()` が担当する。通知遅延時の旧画面再公開だけを止める。
- タブ操作権を有効に保持している場合の通常の「はじめから」は従来どおり機能する。別タブで操作権を再取得した場合も既存の `claim()` 契約に従う。
- 史実データ・勢力配置・ゲームバランス・セーブ形式・IndexedDB構造・シナリオBINは無変更。クロスタブ間のDBトランザクション排他は従来どおり保証しない。

## 検証と留保

- `tests/run_tests.js` に実 `GameManager.startNewGame()` と `loadScenario()`、実 `TabSessionCoordinator` を用いた回帰を追加。通知遅延中、旧タブのシナリオ一覧とゲーム画面が公開されないこと、失効後にBIN読込が開始しないこと、所有タブの正常な開始が保たれることを検査。
- 実ブラウザのバックグラウンド制御差や複数ウィンドウをまたぐストレージ通知配信順序の全端末実証ではない。エラーを人工的に発生させる本編長期観戦試験は実施していない。
- 修正前は既存回帰1,390件成功、従来の配布対象外フォント確認1件失敗に加え、追加回帰1件失敗。修正後 `node tests/run_tests.js` は **1,391件成功／1件失敗**。失敗は配布仕様上同梱しない `data/fonts/title-abashiri-mincho.woff2` の実ファイル存在確認であり、ゲームロジックに新たな失敗はない。
- `node tests/run_visual_tests.js` は起動直後のChromium DevTools一覧が空の時点で判定して1回失敗したが、同じ製品コード・同じ検査を再実行して **24項目成功**。初回の失敗はテスト環境のブラウザ起動タイミングであり、本体の描画不具合ではない。
- `python tools/check_manual.py` はルールID、相対リンク、旧原文2,283行の保全に成功。
- `python tools/verify_excel_bin_parity.py` は共通・1560・1570の管理ExcelとBIN一致。
- `node tools/verify_release_sources.js` は主要数式 **64,644件一致**（12,126＋26,259＋26,259）。
- `python tools/simulation/test_player_focus_sim.py` は近似シミュレーター **4件成功**。本編の長期自然進行ではない。
