# A-146 謀反成功後の別諸勢力所属予定の未登場一門を保護（r817）

## 到達可能性・原因

謀反成功（`IndependenceSystem.planCoupDetatOrRebellion()` の `rebel_win`）後、旧大名・敗残家臣と血縁を持つ未登場武将を浪人化する処理は、`clan` が旧主家または0かだけを条件にしていた。通常の諸勢力所属予定者は `clan=0`、`belongKunishuId>0` のため、別諸勢力へ登場予定でも旧家の敗残者として早期元服・浪人化し、予定所属を保持したまま矛盾する状態となった。

開始データに実在する血縁関係として、1560年河野家・河野通宣と来島衆予定の得居通幸・来島通総、因島衆予定の村上吉充・村上亮康などを確認。謀反勝利は通常プレイで到達する戦闘結果である。特定年の該当謀反が自然観戦で発生したという主張ではなく、実装経路と開始データの照合を前提とした再現である。

## 再現・修正

既存r779の実際の謀反勝利の結合テストへ、他諸勢力予定の出生済み・未出生一門、および所属未定の出生済み一門を追加。修正前は予定諸勢力の出生済み一門が `unborn` から `ronin` へ変更されて失敗し、別諸勢力の将来所属を侵害した。

旧家一門の未登場者候補に `belongKunishuId === 0` の条件を追加。既存の旧主家予定者・所属未定者の早期元服、出生前の旧主家一門の将来の浪人予定化、敗残者の逃亡先、城主更新の一括確定は維持。新しい候補選出Systemは作らず、独立Systemは「誰が敗残者か」を判断し、所属と所在は `AffiliationSystem` の既存の低レベル窓口に委譲する。

修正後は既存回帰を含め、検証用に既存フォント4本を一時配置したロジックテスト **1,334件成功・失敗0件**。フォント未配置時は1,333件成功・1件失敗（タイトルフォント実体検査のみ）。`check_manual.py`、管理Excel/BIN照合、主要数式検査、近似シミュレーション4件は合格。PC・スマホ・低メモリスマホの表示回帰は合格。長期自然観戦による全分岐は未実施。
