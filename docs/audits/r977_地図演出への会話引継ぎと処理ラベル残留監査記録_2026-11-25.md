# 戦国覇道 r977 — 地図演出への会話引継ぎと処理ラベル残留
監査日：2026-11-25（日本時間）／SH-BUG-012

## 正本・実到達性
ライブラリ直近のr976完全版（93,074,615バイト、内部r976）を基準とし、既存ファイルをZIPの内容と照合。現行ARCHITECTURE.md、マニュアル運用規約、技術リファレンスのダイアログ引渡し規則、過去の月次会話保持・災害地図・戦争引継ぎ監査を確認した。
- IndependenceSystem.executeRebellion は独立・寝返りの宣言と改名通知を await した後、地図guard、playBattleBlink、playCaptureEffect、色更新・地図再描画、結果通知の順に処理する。月末史実イベントからの強制独立ではEventManagerの月次holdが有効。謀反のAI側も同じ点滅、他家戦争の開始・戦争終結の点滅・制圧も共通APIを使用する。
- showDialogAsync のPromise完了は、会話が非表示になったことを意味しない。次の会話のためのhandoff猶予・hold中、点滅へ明示的に引き渡さなければ旧会話が残り続ける。r976実ブラウザPC fixtureでは点滅20、制圧85、計105観測フレーム全てで宣言通知が残留。点滅→制圧の境目でも旧通知と処理ラベルの非表示クラス欠落を確認（ラベルの実表示は親opacityにも依存する）。
- モーダル暗幕も次画面公開まで保持する設計なので、明示地図への移行では不要。renderMapの独自hide-text判定は月次遅延・地図演出の共通状態を上書きし得た。

## 修正
- 既存の点滅・制圧ラッパーをwithMapEffectPresentationに置換。共通のcompleteDialogToViewHandoffで完了済み会話を閉じ、暗幕監視の既存窓口に明示的な地図公開を伝え、必要時は既存のpaint待機を通してからカメラ・Canvas演出へ進む。会話の月次holdは維持し、次の会話は従来のキューを使用する。通常閉鎖がpaint待ちなら既存finalizerで一度だけ閉鎖する。
- 地図guardをカメラ前から演出終了まで共通ラッパーで保持し、内部の重複取得・解放を除去。guardの既存カウントに基づき処理ラベルを隠すため、親guardが残る独立の連続演出間でも復帰しない。renderMapもapplyAIGuardTextStateを使用。AI進捗の正規化は地図guard中を対象外にする。
- 新規暗幕・固定待機時間・独立固有フラグは追加しない。戦闘・独立判定・所属・城色計算・通知設定・各演出時間・画面外形は無変更。災害専用地図は準備完了時の既存引継ぎを維持。史実会話中の舞台転換カメラは会話連続表示の既存仕様を変えない。
