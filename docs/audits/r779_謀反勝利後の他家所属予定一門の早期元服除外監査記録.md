# A-105 謀反勝利後の他家所属予定の未登場一門を早期元服の対象から除外（r779）

## 実ゲームでの到達性と修正前の症状

月末の独立・謀反判定や強制謀反イベントから `IndependenceSystem.planCoupDetatOrRebellion()` の謀反成功（`rebel_win`）へ進むと、敗れた旧大名の一門と敗残者の一門で `unborn` の人物を捜し、既に生まれた者を浪人として早期元服させる。従来の検索は血縁 (`familyIds`) の一致だけで、当該人物の**予定所属家**を確認していなかった。ゲームの家系は婚姻・養子・遠縁を含むため、旧主家とは別の大名家に登場予定の人物も血縁に含まれ得る。

実際の1570年「姉川」のシナリオと共通マスターで、遠山景任（旧家ID 12）と織田勝長（予定所属ID 1、1565年生、1577年登場）の親族連結が存在することを `FamilyLinker.rebuildAllFamilyIds()` で確認した。1570年に遠山家への謀反が勝利すると、旧処理は織田家所属予定の勝長を浪人化し、予定所属・所在を失わせる可能性がある。1560年・1570年双方で同種の家系連結と異所属予定が複数ある。

本体の `IndependenceSystem`・`AffiliationSystem` を接続し、謀反勝利の通常実装分岐を固定戦果で再現した。修正前は他家所属予定の未登場一門が浪人となり、所属家と予定拠点が変更された（検査 1 件失敗）。野戦のランダム結果を自然発火させた長期E2Eではなく、到達可能な勝利結果での結合検査である。

## 最小改修

- `unborn` の一門の抽出に、`b.clan` が旧主家 `oldClanId` または無所属 `0` である条件を追加。他家所属予定者には所属・生死・所在の変更を加えない。
- 旧主家所属予定または無所属の一門については、従来どおりその年までに出生していれば早期元服し、未来の出生予定者は `unborn` のまま将来の浪人予定所属へ移す。年齢・生死・家系・戦闘結果、浪人処理と逃亡先の決め方は改めない。
- `LifeSystem` の当主・国主の後継候補に既にある「本人の所属が当該家または無所属」の判断と一致させ、新たな親族キャッシュや所属正本を導入しない。

現行マニュアルの `所属／登場は各専門Systemの責務` と、開始データの予定所属を守る規則に沿う局所修正であり、ルール変更はない。`ARCHITECTURE.md` および `TECHNICAL_REFERENCE.md` は変更不要。

## 検証

- 実装分岐を通す回帰で、旧主家所属予定者が早期元服し確定した逃亡先へ入る正常系、他家所属予定者の `clan / status / castleId` 不変、生年がまだ先の旧主家一門が現在年に登場しない点を確認。
- テストの red（r778 動作）: 1,266件成功・1件失敗。green（修正後）: 1,267件成功・0件失敗。
- `node tests/run_tests.js`、`python tools/check_manual.py`、`node tools/verify_release_sources.js`、`python tools/simulation/test_player_focus_sim.py`、`node tests/run_visual_tests.js` をリリース版で検査する。
- ゲーム長期自然観戦による全分岐確認は未実施。各テストを自然進行と同一視しない。
