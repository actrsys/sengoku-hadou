# r876 野戦兵科画像下部の兵数重ねと凸本体の視認性を修正

## ユーザー指示と実際の問題
- r875では、兵科画像（24px）と兵数（10px）を縦に積み、全体を凸本体の下端に揃えていた。そのため画像・数字が凸本体へ重なり、凸が見えない状態となった。
- 兵数の黒い輪郭は上下左右に独立した斜め4方向の `text-shadow` に頼っており、数字ごとに黒い影が左右へずれて見えた。
- 最新の指示は、**兵数を兵科画像の下部に完全に重ね、数字を画像より前面に置くこと、凸本体は別途視認できること、凸の向きに依存して兵科・数字が回転・移動しないこと**。

## 実装修正（CSSだけで処理の正本を維持）
- `css/style.css` の既存の `.fw-unit-status-wrap` を、凸本体の外側の上方へ固定（`bottom: calc(100% + 1px)`）。独立DOM `.fw-unit-icon` とその向き変更は維持。
- 兵科画像を24pxの絶対配置にし、兵数を同じ24px枠の下端に絶対配置して `z-index: 1` で画像より前面に重ねる。
- 旧斜め4方向の黒い `text-shadow` を除去し、`-webkit-text-stroke: 0.8px #000` と `paint-order: stroke fill` で均一な黒い縁取りに変更。左右中央揃えを維持し、余分なletter-spacingを廃止。
- 画像・兵数の位置は `.fw-unit` 本体の大きさと方向に無関係で、通常部隊と移動プレビューの既存DOMを共用する。
- `js/field_war.js` のレンダリング・兵数更新・戦闘ロジック・画像ファイルは変更していない。

## 再現・検証
- r875へ新仕様のテストを先に適用すると、兵科画像が凸の上方にない条件で **1件失敗**。修正後はロジック **1420件成功・0件失敗・1件スキップ**。
- Chromium実ブラウザで PC・スマホ、3兵科、兵数の異なる3種類の凸サイズ（16/24/31px）、6方向、通常部隊・プレビューの位置とレイヤーを検査。
- さらに実際の兵科WebPと凸型PNGマスクをインライン化したブラウザ描画のスクリーンショットを確認し、数字の前面表示、均等な黒縁、凸型本体の視認性を目視した。検証用HTML・画像・スクリプトは配布ZIPに含めない。
- 既存のPC・スマホ画面回帰、管理Excel・BIN等の検査はリリース確認として別途実行する。

## 旧版との関係
- r875で確立した「凸の回転と画像・兵数を分離するDOM構造」「カラーWebP・枠なし」は維持する。
- r875の**縦積みレイアウト**のみ今回のユーザー指示に基づき廃止。古いCSSの上に新しい上書きを重ねず、同じ規則を置換する。
