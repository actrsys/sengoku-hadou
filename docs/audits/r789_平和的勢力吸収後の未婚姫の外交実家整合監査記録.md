# A-114 平和的勢力吸収で引き取った未婚姫の外交婚姻整合（r789）

## 対象と到達性

r788を基準に、`AffiliationSystem.absorbClan()` から平和的勢力吸収後の未婚姫移管と、後日の `DiplomacyManager.applyMarriageLinkData()` / `refreshMarriageRelation()` を調べた。通常の臣従願・AI同士の月初臣従申し出・史実イベントは同じ吸収窓口に到達する。`command_system.js` の外交婚姻候補は `currentClanId` と未婚状態を使うため、吸収された旧家の未婚姫も新家から実際に嫁がせられる。

## 修正前の再現と原因

旧家(2)が新家(1)へ吸収され、旧家の未婚姫(900)が新家へ移管される正常な状態を用意。新家の姫名簿に登録された姫を他家(3)の武将へ通常外交婚姻させると、成立直後は新家・他家の `isMarriage=true` となるが、共通照合 `_hasActiveMarriageBetweenClans(1, 3)` は姫の `originalClanId=2` を参照するため、`refreshMarriageRelation(1, 3)` で `false` に戻る。既存1,284件成功、新規結合テスト1件失敗を確認した。

## 最小改修

- `AffiliationSystem.transferUnmarriedPrincesses()` に限定し、移籍対象である未婚姫の `originalClanId` を `currentClanId` と一緒に新家へ更新する。これは既存の戦争による滅亡時の未婚姫引取（`LifeSystem.checkClanExtinction()`）と同じ扱い。
- 既婚姫は対象に含めず、既存の夫婦参照・元家・姫名簿を変更しない。出生・実父母の系譜IDを変更しない。婚姻成立・解除の判定は既存の `DiplomacyManager` を唯一の正本とする。
- 外交全般の判定や新しい状態フラグ、マスター・セーブ形式は変更しない。

## 結果と限界

- 新規結合テストは修正前失敗／修正後成功。既婚姫の出身家と現在所属が維持されることも確認。
- ロジック回帰1,285件成功・失敗0件。マニュアル検査、管理ExcelとBINの整合性検査、シミュレーション補助4件、PC・スマホ画面回帰は合格。
- 長期自然観戦での全外交乱数分岐、手動操作によるすべての婚姻画面の通し確認は未実施。
