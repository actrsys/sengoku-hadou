# r839 諸勢力取込の功績確定と派閥・城主選出順序

## 通常操作の到達経路と修正前再現

- 自領の拠点にいる取込可能な諸勢力に対してプレイヤーが取込命令を実行し、成功した場合の `KunishuSystem.executeKunishuIncorporate()` が対象。
- 本体の `AffiliationSystem`・`FactionSystem`・`KunishuSystem` を結合した既存のr786取込fixtureを用い、命令担当者の功績490を指定した。取込成功により本体仕様どおり功績60が加算され、550になる。
- 修正前は所属者の取込直後に `FactionSystem.updateFactions()` が功績490を観測し、その後に功績550へ更新された。派閥主候補の功績500以上の資格と城主候補の実績評価が、同一命令の最終状態と食い違う。
- 再現テストを修正前に追加し、実際の再編入力値が490、終了後が550であることを確認（追加回帰が失敗）。この条件は正常なプレイヤー取込命令と通常の功績成長で到達可能。特定の史実登場時期や改造セーブは前提にしない。

## 対応

- 諸勢力所属者の一括仕官を完了し、諸勢力の壊滅を確定させた後、同じ成功命令による担当者の功績・承認欲求を先に更新する。
- それから既存の `game.updateCastleLord()` と `FactionSystem.updateFactions(playerClanId)` を従来と同じ各1回だけ呼ぶ。城主や派閥の算式、新規System、特殊な派閥クリア処理は追加しない。
- 取込成否、功績加算量、承認欲求、兵力・士気・訓練度、履歴・画面、旗揚げ・鎮圧・通常所属変更は維持する。

## 検証範囲

- 修正前に落ちた再現テストは、修正後に成功。成功時の城主選考・派閥選出は双方とも功績550を観測し、選考・再編回数は従来どおり各1回。
- 既存の一括取込4人・城主任命・地図描画・諸勢力旗揚げの回帰を維持。
- 長期自然観戦と実際のプレイヤー画面での取込クリック操作は未実施。追加テストは本体ロジックを呼ぶ限定実行であり、全状況を保証しない。
- マニュアルの追加仕様は現行規則の既存責務段落だけへ統合し、技術リファレンスの保護対象本文を変更しない。
