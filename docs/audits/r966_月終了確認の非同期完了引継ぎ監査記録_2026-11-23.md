## 1. 監査範囲と問題
- `js/turn_manager.js` の `checkAllActionsDone()`。通常プレイで全武将の行動が終了した際の遅延確認「今月の命令を終了しますか？」。
- `js/ui.js` の `_confirmFinishTurn()`。PC/スマホ共通の手動「命令終了」確認。
- 両方が `UIManager.showDialog(..., { closeBeforeOk: true })` の確定コールバックから `game.finishTurn()` を呼ぶが、r965では返り値を破棄した。
- `game.finishTurn()` は `TurnManager.finishTurn()` に委譲される非同期処理であり、`tryProcessQueuedWatchReturn('turn_complete')` のawaitと後続のターン継続予約を含む。`UIManager.processDialogQueue()` は `closeBeforeOk` の共通幕をコールバックのPromiseが完了した時点で解放する契約である。
- そのためr965では通常経路から非同期完了契約が成立せず、処理中の背景表示が早期公開され得た。**実端末のちらつきそのものは未観測**。AI判断・年月計算・セーブ内容に影響する証拠はない。
