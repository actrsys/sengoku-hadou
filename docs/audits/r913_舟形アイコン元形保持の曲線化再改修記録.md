# r913 舟形アイコンの元形保持・曲線化再改修

## 対象
野戦海上用の舟形アイコン12種、共通影1種。正本r912から実施、形状基準はr911の元画像。

## 不具合の確認
r912では、舟形を新規に造形して元画像にない左右のくびれや内部の装飾線・ハイライトが生じた。ユーザー指摘どおり不適切。

## 修正方針と結果
- r911の元画像の輪郭を高さ方向にサンプリングし、オーバーシュートを抑えた単調補間で滑らかにした。
- 上端・下端の基本形と幅を維持し、新しい切れ込みや凹みを作らない。
- 画像内部は元画像と同一の単色。黒外周線と陣営色の縁取りのみ。総大将版は白枠。装飾線やハイライトなし。
- 高解像度に描画して縮小し、透明WebPとして保存。海上影はr911の元影を滑らかに処理した。
- 画像のファイル名、寸法、陣営色、識別、ゲームのロジックとレイアウトは変更なし。
- r912で追加した不要な装飾と形状を全種から撤去した。
