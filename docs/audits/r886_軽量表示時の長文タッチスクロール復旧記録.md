# r886 軽量表示時の長文タッチスクロール復旧

## 現象と原因
- スマホ軽量表示では、タイトルの利用規約・クレジット・ライセンスの詳細本文に `CustomScrollbar` を生成せず、OS標準のスクロールを使用する。
- `js/game.js` の `initializeGameApp()` にある document共通 `touchmove` 抑止は、既存の `.scroll-wrapper` 等の固定クラスだけを許可していた。標準スクロールの `.title-info-detail-body` はこの条件に該当せず、指を動かすたびに `preventDefault()` されていた。
- 同じ条件は、縦長時に実際にスクロール可能なタイトル・各種モーダル内の本文にも及び得た。

## 改修
- `js/game.js` に `canUseNativeTouchScroll(target)` を置き、既存の許可対象を維持したまま、タイトル／モーダル内の祖先要素が実際に縦スクロール可能 (`scrollHeight > clientHeight` かつ computed `overflow-y:auto|scroll`) な時だけネイティブのタッチ移動を許す。
- 地図等の非スクロール領域では引き続き `preventDefault()` を適用する。軽量版専用の重いスクロールバーや独自ドラッグを再導入しない。
- 利用規約・クレジット・ライセンスの本文とロード・戻る・表示モード・ゲームルールに変更なし。

## 検証
- 新規のロジック回帰：軽量版長文、本文内の子要素、縦長タイトル、シナリオ一覧は許可し、非スクロール領域および地図操作の既存制約は維持。
- Chromiumモバイルタッチ操作の再現（390×844、軽量CSS、利用規約本文）：r885では同条件のスワイプ後 `scrollTop=0`、r886では `scrollTop` が200px以上進んだ。
- 同じ軽量表示でライセンスの長文もスワイプにより進むことを確認。ライセンス全文末尾までの連続スワイプおよび実機固有の挙動は未検証。
- `node tests/run_tests.js`：1,425件成功、0件失敗、フォント実体比較1件スキップ。
- `node tests/run_visual_tests.js`：PC／スマホ既存画面回帰成功。
