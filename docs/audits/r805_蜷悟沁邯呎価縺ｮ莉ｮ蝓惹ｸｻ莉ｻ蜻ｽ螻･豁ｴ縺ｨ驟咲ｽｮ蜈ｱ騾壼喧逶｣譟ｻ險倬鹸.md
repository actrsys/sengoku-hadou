# A-133 同城継承での仮城主を防ぎ後任配置を共通化（r805）

## 到達経路と再現

通常の国主死亡・大名死亡・生前家督相続では、後任者が先代と同じ拠点に既に在城していることがある。r804 までの `LifeSystem.handleCommanderDeath()` と `setupNewDaimyo()` は、同一拠点でも後任者を `AffiliationSystem.leaveCastle()` で在城名簿から一時退去させていた。`leaveCastle()` が直後に城主を再選出するため、その時だけ残る別の家臣が城主として履歴化され、その後すぐ後継者が城主となる。さらに在城名簿の順序も不必要に変わる。

実コードの所属・城主処理を利用した回帰テストを追加し、**r804 では大名・国主それぞれで `【城主任命】` の仮任命履歴を実際に再現**した。内部状態の破損を前提とせず、通常の単発継承で同じ城にいる候補を選ぶ経路で発生する。

## 改修

- `LifeSystem._placeSuccessionSuccessor()` を設け、大名・国主の後継者の在城配置を一か所で確定する。所属更新・着任・在城履歴は従来どおり所属Systemの `leaveCastle()` / `setActivityStatusRaw()` / `transferClanRaw()` / `setCastleIdRaw()` へ委譲する。
- 先代と同城なら `leaveCastle()` を行わない。別城から実際に移動する現役・浪人だけを旧城から退去させる。元所属での在城期間を記録する条件、外部一門の扱い、忠誠100、妻の所属同期は従来どおり。
- 同時死亡による城主確定保留では、実際に移った後任の出発元と到着先だけを対象に加える。役職ごとの後任候補、順位、国主席の解散、大名の家督名・外交・威信の変化、通常時の即時城主確定は維持。
- 後任が同城／別城にいる分岐を両役職で確認するテストを追加。旧来の生前家督・国外一門の妻追従に関するソース監査は、新しい共通実装を検証する形へ更新した。
- ルール追加ではなく現行マニュアルの継承条文に同城配置の不変条件を追記。ゲームバランス・管理Excel・BIN・画像・セーブ形式は変更していない。

## 再現・回帰

- r804 の LifeSystem と新規回帰テストを組み合わせると、同城後任者の退去・再入城途中に別の家臣を城主へ仮任命した履歴が大名と国主の両方で発生し、新規2件が失敗。
- r805 では仮城主任命は発生せず、同一拠点の在城名簿の順序も維持。別城からの後継者転任・軍団解散・妻の同期は既存回帰で確認。
- 完全版のゲーム本体・データ・ツールは保持し、フォント4本のみユーザーが手動配置するため同梱しない。`data/fonts/` は空ディレクトリとしてZIPへ収録する。
