# r872 利用規約・クレジット・ライセンスの三分離

## 対象と意図

r871（規約統一・クレジット案内文削除済み）を正本とし、明示されたユーザー方針に従ってタイトル画面「情報」を三分離した。作品独自素材の利用条件と、第三者ライセンスの著作権表示を同じ文書に重複させない。

## 変更

- `TERMS_OF_USE.txt` を追加。従来 `THIRD_PARTY_LICENSES.txt` 冒頭にあった作品独自素材の複製・抜取り・再配布・転用等の条項と法令上の例外を移管した。新しい禁止行為・利用同意の強制は設けない。
- `THIRD_PARTY_LICENSES.txt` を第三者素材の共通条項と、既存のMIT・zlib・SIL OFL等の表示に限定。個別条件優先条項の「本規約」の指す範囲を、分離後の両文書に合わせて明記した。第三者ライセンスの原文は保持する。
- `index.html` の情報メニューへ「利用規約」を追加し、並びを利用規約／クレジット／ライセンス／問い合わせ／戻るに変更。
- `js/app_bootstrap.js` は既存モーダルを維持し、両TXTの読込・失敗通知を共通関数へ集約。文書ごとの非同期応答に対する表示タイトル一致判定も共通化。
- 既存のロジックテストとPC・スマホのタイトル配置回帰を更新。クレジットの素材提供元表記とライセンス原文は維持した。

## 判定・守るべきこと

文書本文の正本をそれぞれ一つにする。クレジットへ規約説明・ライセンス誘導を再追加しない。配布物とゲーム内表示で別の文面を管理しない。`js/config.js` の版はUI機能追加のためr872。

## 検証

配布ZIP作成時に、既存の `node tests/run_tests.js`、`node tests/run_visual_tests.js`、`python tools/check_manual.py` と配布ZIPのCRC・差分を確認する。ゲームルール・管理Excel・BIN・画像・音声は変更対象外。
