# r822 1560年「桶狭間」の死亡済み武将の官位整合

## 実データの不整合と到達性

r821では1570年「姉川」に限って死亡済み武将13人の官位を整理した。両シナリオの初期データを同じ死亡条件（`endYear < startYear` または `startYear == 9999`）で横断照合すると、1560年「桶狭間」の死亡者2人に官位が残っていた。

- 田向重継（ID 1010015、1556年没）：官位ID 88
- 田向重治（ID 1010019、1535年没）：官位ID 17

開始時点では両名とも死亡扱いとなるため、現役人物に付与する初期官位と不整合。`CourtRankSystem` で死亡者の官位を現役として扱わない既存の安全確認は維持する。既存のシナリオ開始処理から到達する原データの不整合であり、人工的な破損データではない。

## 正本と変更内容

`管理用Excel/1560_okehazama.xlsm` の `warriors_state` シートの `courtRank` 列の2セルだけを空にし、`data/scenarios/1560_okehazama/scenario.bin` の同じ2件の官位を空にした。管理Excelはアーカイブ内部の該当セルXMLだけを差し替え、ほかの49エントリは展開後のバイトが一致することを確認。数式、マクロ参照、書式、ほかの人物・シナリオには触れない。

初期官位・人物状態の正本は従来どおり管理Excel／共通マスターであり、BINは生成派生物。検索や死亡処理に重複した例外を増やしてデータ誤りを隠すことはしない。現役の大名・国主・城主・諸勢力頭領の初期資格と所属についても両シナリオを検査し、今回対象の役職上の不一致は検出しなかった。
