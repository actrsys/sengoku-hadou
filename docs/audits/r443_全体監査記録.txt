戦国覇道 r443 継続監査記録（r442を基準とする）

【監査方針】
修正には明確な問題・再現条件・設計上の根拠を求める。どちらにも合理的な長短がある仕様の好みは変更しない。

【対象】
・セーブデータの復号・構造検査と、スロット一覧表示への引き渡し
・タイトルのセーブ有無非同期判定とロード可能フラグへの反映
・シナリオ/保存の寿命管理に関連する再入経路
・PC/スマホ表示、自動テスト、ゲームシミュレーション、配布管理用ExcelとBIN

【確認した問題】
1. SaveLoadViewが外部ファイルから復元し得るセーブの clan.name / scenarioName / saveTime / mapThumbnail を、HTMLテンプレートへ無加工で挿入していた。
   ・任意のタグや属性区切りを保存値へ紛れ込ませた場合、保存一覧のマークアップに混入できる。
   ・復号やロード可否の構造検査では文字列のHTMLとしての安全性は保証されない。
   ・対応：SaveLoadView内で動的文字列をHTMLエスケープ。縮小図はゲーム生成互換のbase64 JPEG/PNG/WebP画像のみ表示し、その他は既存のNO DATAにフォールバックする。
   ・同じ画面構造、保存媒体、ソート規則、表示形式は維持する。正当な日本語・数字の見た目は変えない。
   ・再現回帰：保存内容にタグ、イベント属性、SVG画像、属性区切りを混ぜたスロット表示で、HTML構造を作らないことを確認。
2. タイトル画面のロード可否確認は、UIの世代を確認する前に SaveManager.refreshLoadAvailability() が game.hasSaveData を更新していた。
   ・読込が終わる前に別画面へ遷移/保存すると、旧タイトルの「データなし」判定が後発状態を false に戻せる。
   ・対応：UIが持つ既存のisCurrentをSaveManagerに渡し、結果をgame.hasSaveDataへ反映する前に確認。最新確認の従来動作は維持。
   ・再現回帰：旧確認が失効した後に false が返っても、新たな true を変更しない。最新確認では正しく変更する。

【見送った変更】
・ゲームバランス、AIルール、歴史イベント、地図Canvas、戦闘、コマンド階層、シナリオ設定、旧セーブ互換は現状維持。
・保存データの暗号化方式、表示順、任意のUI全面リファクタ等は、今回の問題を直すために必要がないので変更しない。
・コードの見た目だけの整頓や、パフォーマンス計測のない最適化は実施しない。

【検証】
・通常回帰：661 passed / 0 failed（問題再現2件を追加）。
・PC/スマホ表示回帰：16グループ成功（PC/スマホ/低メモリ地図切替を含む）。
・シミュレーション：4件成功。
・管理用Excel/BIN：共通、1560、1570すべて出力フィールド一致、存在・数式検査正常。
・既存の管理用Excel、BIN、画像アセットは変更なし。
