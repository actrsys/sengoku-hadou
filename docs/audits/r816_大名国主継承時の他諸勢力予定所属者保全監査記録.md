# A-145 大名・国主の早期継承で別諸勢力の登場予定者を奪わない（r816）

## 到達可能性と修正前の再現

`LifeSystem.executeDeath()` から通常の家督・国主継承に進むとき、`LifeSystem._collectSuccessionCandidates()` は現役一門、出生済み未登場一門、AI用外部一門の順に候補を収集する。r815で外部一門経路の死亡者・未登場者は除外したが、未登場一門経路には `clan === 0` だけの条件が残り、**別の諸勢力への登場予定を持つ未登場一門**が早期元服候補として混入していた。

1560年「桶狭間」の開始データと本体 `FamilyLinker` / `LifeSystem` で再現した。河野家当主・河野通宣（ID 1049003）の後継候補順位では、来島衆（諸勢力ID 60）に登場予定の得居通幸（ID 2060005、登場予定1569年）が先頭となり、続いて別諸勢力の村上吉充・村上亮康が並ぶ。現役の河野通直（ID 1049001）より優先されるため、通常の大名死亡で誤った登場先へ元服させ得た。死亡経路は戦死・自然死等で実プレイ到達可能だが、長期自然観戦による当該死亡時点の観測は未実施。

## 最小修正と専門責務

`LifeSystem._collectSuccessionCandidates()` の未登場一門資格を、**同じ大名家に所属予定**か**所属先未定（clan=0かつbelongKunishuId=0）**に限定した。別諸勢力所属予定者を除外する一方、現役の諸勢力所属一門、浪人一門、同家所属予定・所属未定の出生済み未登場一門は従来どおり候補に残す。家督と国主の順位、同軍団補充、実際の元服・所属移動・城主確定、諸勢力頭領側の継承ルールは変更しない。候補選考は `LifeSystem`、所属更新は `AffiliationSystem` の正本を維持し、新規の汎用ラッパーは追加しない。

## 再現と回帰

- 新規の共通資格回帰と1560年実データ回帰の2件は、r815では両方失敗。修正後は成功。
- r815の従来正常系回帰のうち「出生済み未登場者」は所属先未定の設定へ訂正し、正常系として保持。現役諸勢力一門・浪人一門の資格も継続確認。
- 1560年河野家の後継候補は、別諸勢力への登場予定者を除外して現役の河野通直が先頭となることを実データで確認。
- フォント未配置の配布環境ではロジック1333件成功・フォント検査1件失敗。検証環境へ既存フォント4本を一時配置した場合はロジック**1334件成功・失敗0件**。検証後、フォントを削除。
