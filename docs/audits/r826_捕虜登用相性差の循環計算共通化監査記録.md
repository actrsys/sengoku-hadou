# r826 捕虜登用における相性差計算の共通化

## 到達性と修正前再現

戦後処理の捕虜登用では、`WarManager.calcPrisonerHireProb()` が相性補正を計算する。通常の人事判定では `PersonnelRules.calcAffinityDiff()` が0～99の循環値から0～50の相性差を返すのに対し、捕虜登用のみ `Math.abs()` で直線距離を計算していた。そのため相性0と97を97差と解釈して、近い相性なのに最も不利な-0.3補正を与えていた。

1560年「桶狭間」の実データから、織田信長（ID 1006006、所属1、魅力98、相性0）と斎藤利治（ID 1005005、所属6、忠誠95、相性97）を検証対象とした。両者は開始時点で登場済みの別勢力武将で、織田家が斎藤家の利治を捕縛して登用する戦後処理から到達し得る。検証はその捕虜状態・戦闘経過全体の自然プレイ再現ではなく、現行本体の確率計算に実データを与えた条件再現である。

乱数を0.5で固定（乱数補正0）、一門・宿敵・旧大名登用補正なしとして、修正前の非滅亡時の結果は0%（期待約21.58%）、滅亡時は約21.58%（期待約61.58%）だった。新規回帰テストは修正前に失敗した。

## 改修と責務

- `js/war_effort.js` の捕虜登用相性差を `PersonnelRules.calcAffinityDiff()` に置換。相性補正の閾値・値・適用順序、他の確率補正、戦後処遇の責務と手順は変更しない。
- ほかの人事・調略が既に使っていた共通計算を再利用し、新しい計算式や新規Systemは追加しない。
- 現行マニュアルの既存責務表へ循環相性差の正本を明記。技術リファレンス原文・管理Excel・BINは変更しない。
- 通常登用・捕虜登用の現役一門補正、宿敵判定、AI引抜候補の資格は別の既存仕様として維持。実害を再現していない変更は加えない。
