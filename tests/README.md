# 自動テスト

外部ライブラリは不要です。Node.js がある環境でプロジェクト直下から次を実行します。

```bash
node tests/run_tests.js
```

Windows ではプロジェクト直下の `run_tests.bat` をダブルクリックしても実行できます。

現在は、設定値の中央管理、外交通行判定、兵力自動配分、援軍編成、SkillManager の境界、SelectorModal の共通初期化、HTML の script 参照などを検査します。

リファクタ時は「現在の挙動を固定するテスト」を先に追加してからコードを移動する方針です。

## ビジュアル / レイアウト回帰テスト

Chrome / Chromium / Edge と Node.js 22+ がある環境では、実ブラウザのレイアウトエンジンを使って主要UIの寸法を検査できます。

```bash
node tests/run_visual_tests.js
```

Windows では `run_visual_tests.bat` を利用できます。ブラウザを自動検出できない場合は `CHROME_PATH` に実行ファイルを指定します。

現在の対象はPC版武将詳細の能力ゲージ（80 / 100 / 110 / 120）です。100の通常枠、101以上の限界突破、120で予約領域右端へ到達すること、右側情報欄へ侵入しないこと、ゲージ高が潰れていないことを実寸で検査します。

通常はスクリーンショットを一時領域へ生成して破棄します。手元で確認画像を残したい場合は `KEEP_VISUAL_SCREENSHOT=1` を設定して実行すると `tests/visual/last_busho_gauge.png` に保存します。

ピクセル完全一致はOS・フォント描画差に弱いため、現段階ではレイアウト実寸を正本の回帰条件としています。
